## 修复

| 问题 | 处理 |
| --- | --- |
| 下拉菜单不像笔刷 | 改为同尺寸横向 pill：字号 A 档位 / 颜色圆点 / 关闭；选择后立即收起 |
| 点击页面无反应 | 文字菜单打开时不再拦截画布；点击/长按页面先关闭菜单，再继续创建/长按 |
| 点击框内无反应 | 延迟到触摸结束后打开编辑器；角手柄不再抢占首次点击；真实 Activity 测试验证焦点保持 |
| 长按无菜单 | 文本框：复制/删除；空白页：粘贴（在按压位置创建文本框） |
