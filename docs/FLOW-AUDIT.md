## 下一步顺序

1. **真机可用**：用 Focus Pen Pro 在飞行模式验证读写、选字、图片、尺、字典与系统 IME；记录型号、系统、密度、压力范围、按键事件和延迟。其他小米笔复用标准路径，逐支确认实际能力。
2. **可恢复**：真实低空间/大文件/权限取消、杀进程、重启、导出与备份恢复；确认失败不丢现有数据。
3. **可发布**：部署反馈 HTTPS，完成资源权利复核、生产签名与密钥备份，再发布首个 APK + annota-update.json，走通真实更新安装。当前不制造空 Release。
4. **细节收口**：统一失败/取消/空状态的原生样式；完善永久删除与空间管理、指南热点和真机视觉验收。唯一 3B Logo 已确定，不再保留候选。

不在首期增加账号、云空间、跨端同步、OCR、整句翻译、AI 服务、付费或大量模板。详细历史证据与限制见 [实现状态](IMPLEMENTATION-STATUS.md)，发布操作见 [分发方案](DISTRIBUTION.md)。

本轮真实 UI、系统导出、进程/模拟器重启与同签名升级的复跑步骤和证据见 [阅读器验收](READER-ACCEPTANCE.md)。
