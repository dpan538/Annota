# 流程闭环审计

截至首次仓库整理，完成的是交互原型与数据参考实现；原生功能由独立 Android 任务推进。下表的“已做”不表示已在正式 APK 或 Xiaomi 硬件上完成。

| 流程 | 原型已做 | 仍缺的闭环 | 验收标准 | 优先级 |
| --- | --- | --- | --- | --- |
| 首次启动 | 书库预置两文件、指南跳转 | 私有目录初始化、事务去重、失败恢复、资源许可确认 | 断网首次启动成功；升级与重启不重复添加已删文件 | P0 |
| 导入 PDF → 阅读 | 文件选择入口、示例真实页图 | 通用 PDF 解析、拷贝/URI 权限、进度、加密/损坏/取消状态 | 任意合法 PDF 真正打开；失败不残留假文档 | P0 |
| 阅读 → 退出 → 再打开 | 进度与状态演示 | 可靠持久化、杀进程恢复、横竖屏/缩放正确映射 | 重启后页码、页序、笔迹与图片仍正确 | P0 |
| 写 → 擦 → 撤销/重做 | 笔类、胶囊、尺、图形、合成输入验证 | 原生低延迟笔迹、实际掌触、压力、可恢复存储 | 真机可连续书写，不误触、不丢笔，不因旋转漂移 | P0 |
| 页面管理 | 侧栏、新增、复制、旋转、删除、清空与撤销 | PDF 重组、事务与资源清理、模板更换保存 | 导出与重开保留相同页序、旋转和批注 | P0 |
| 新建快速笔记 | 4 种模板 × 3 种底色、直接开始写 | 原生笔记文件格式、持久化、跨版本迁移 | 改模板/底色不丢笔迹；黑纸默认墨迹清楚 | P0 |
| 选字 → 复制/查词 | 示例文字层、剪贴板回执、词典浮窗 | 通用文字坐标与原生剪贴板、完整 SQLite 接入 | 复制所得与选区一致；离线查词，无结果不转联网 | P0 |
| 字典键盘/手写 | 图标入口与 IME 协议 | 系统手写 IME 与目标设备离线验证 | 飞行模式键盘/手写均能输入，事件不穿透 PDF | P0 |
| 图片插入 | 系统选择器接口、会话预览 | URI 生命周期、资源落盘、缩放/移动/删除 | 重启仍显示正确；选择取消不改文档 | P0 |
| 整理文件 | 收藏、重命名、复制、移动、废纸篓/恢复 | 本地数据库、重名/复制失败/空间不足；文件夹重命名/删除交互 | 文件与索引不失配；可取消；失败状态明确 | P0/P1 |
| 废纸篓 → 释放空间 | 移入与恢复 | 保留规则、永久删除确认、清空与实际资源回收 | 永久删除不可误触；关联资源安全释放 | P1 |
| 导出 → 系统文件 | 原生导出事件与已知文档打印预览 | 真正 PDF 合成、系统保存/分享、失败与取消 | 系统文件可被其他 PDF 阅读器打开，批注与图片完整 | P0 |
| 本地备份 → 恢复 | 目标已明确 | 备份格式、恢复冲突、校验与迁移界面 | 卸载前可自行保管；恢复不静默覆盖原文件 | P1 |
| 设置 → 实际生效 | 四主题、按键、手势、关于 | 原生偏好持久化、能力探测、离线许可页 | 重启保留；不支持的笔功能禁用并解释 | P0 |
| 反馈 → 服务 → 回执 | 弹窗、取消、草稿、提交协议 | 匿名服务、频率限制、失败重试与真正成功回执 | 未收到成功不能清空草稿；不上传私人文件 | P0 |
| 安装 → 检查 → 更新 | 关于入口与事件协议 | 首个签名包、版本信息、下载/校验/权限/系统安装 | 更新失败可重试；覆盖升级后本地数据完整 | P0 |

## 产品与设计窗口还要补的内容

1. 形成加载、空白、失败和取消的统一界面约定，重点覆盖导入、导出、反馈、更新。
2. 补齐文件夹管理、永久删除、存储不足、备份/恢复与重名冲突的小流程。
3. 以真机确认顶部安全留白、触控范围、字体缩放、横竖屏以及浮窗遇到键盘时的位置。
4. 决定最终 Logo，并制作 Android adaptive icon、单色图标与启动页资产。当前三组仅是候选。
5. 许可与来源页离线可读；论文预装授权、实际随包词库与字体逐项复核。
6. 以实际能力校正指南：原生未实现的功能不能写成已上线，正式发布时更新截图和版本说明。

## 交付顺序

- **M1 本地可用**：导入 → 阅读 → 写字 → 保存 → 杀进程 → 恢复。
- **M2 内容完整**：页面/文件管理、导出、字典、图片与备份。
- **M3 真机可靠**：Xiaomi 笔、掌触、低延迟、大 PDF、空间不足与权限拒绝。
- **M4 可公开测试**：签名 APK、匿名反馈、更新下载与覆盖安装、许可和隐私说明。

不在首期增加账号、云空间、跨端同步、整句机器翻译、AI 服务、付费系统或大批装饰模板。
