# Annota 1.2.1.2（第二个 Preview）

**状态：预览版（普通 Release，Latest）。** 稳定版仍为 1.2.0；真机验收仍在进行。

- 版本：`1.2.1.2` / versionCode 26
- APK：`Annota-1.2.1.2.apk`（0deaeaa387eca42f75371003e4349ee5ed02da2f1b036b87ce528dc3799bbed8）
- 1.2.1 反馈修复：残影/铅笔预测默认关闭、橡皮独立大小与局部/整笔、文字输入框、懒加载半页模糊修复。

## 修复

| 问题 | 根因 | 修改 |
| --- | --- | --- |
| 笔迹残影、铅笔像描边 | PRC 预测层被画到所有笔种上，alpha 最高 150，且铅笔用普通 outline 而非 Graphite | 预测默认关闭；铅笔跳过；置信度<0.5 不画；预测画在真实笔迹下方；alpha≤45 |
| 橡皮误擦前后字母/符号 | 橡皮半径绑定画笔宽度（`penWidth*5+5`），默认整笔模式；命中即删整笔 Mark | 独立 `eraserWidth` 小/中/大/特大；局部/整笔可选；整笔只删最近命中对象；局部只切命中 Mark |
| 半页缩放模糊 | 纯平移/懒加载时复用旧 tile plan，新视口没有高分辨率 tile，停留在低分辨率底图 | 视口覆盖检查；不覆盖时重建 tile plan；瓦片请求覆盖当前可见区域 |
| 需要页面内输入文字 | 缺少文字标注与键盘交互 | 新增 Type 工具、页面文本框、拖动/四角缩放、IME 编辑、撤销/备份/PDF 导出 |

## 验证

- 271 项既有 + 新增测试（WritingRegressionTest / TextAnnotationDataTest）在 API 36 ARM64 模拟器、断网、合成输入下运行；真实笔尖、键盘 insets、PDF 阅读器仍需真机验收。
