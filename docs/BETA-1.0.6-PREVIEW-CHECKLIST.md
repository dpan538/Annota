# 1.0.6-preview · Beta 真机测试清单

从现有版本直接覆盖安装，先做本地备份；无需卸载。主页 / 关于应显示 **1.0.6-preview · Beta**。此清单用于 Xiaomi Pad 9 Pro Max，模拟器结果不能代替手感验收。

## 1. 目录和文件动画（重点）

- 在实际大课件中反复开关页面侧栏：左侧展开时右侧连续收窄；整页不闪白、不变透明，阅读位置不突然跳页。
- 连续快速点击目录按钮，中途反向关闭，再次打开；最后状态应与按钮一致，无残留面板或空白占位。
- 在不同缩放比例下打开 / 返回 PDF：向前、返回方向相反，画面不交叉淡化；返回后可以立即打开另一份文件。
- 在系统中关闭动画再试：立即切换，无卡住、移出屏幕或浮层残影。

## 2. 铅笔黑色

- 用黑色铅笔分别轻写、正常写、重写，首先在正常阅读比例判断是否清楚，再放大看纸纹。
- 涂画重叠应加深，倾斜有更宽的阴影；不能变成均匀灰色圆头线。
- 撤销 / 重做、关闭重开、导出 PDF 后外观一致。旧版保存的笔迹保持原样；请用新笔迹比较浓度。

## 3. 离线词典

- 飞行模式下查 `virtual instances`、`high-performance distributed grid`、`workload distribution and coordination functions`。
- 自选其他学科词汇和词组，测试复数、连字符、跨行选区；不要只测上面三个例子。
- 整体词条直接出简释；未整体收录的词组显示“分段释义”。输入夹杂一个不存在的词，应保留该片段并标记“未收录”。
- 首次安装 / 覆盖更新后无需下载词库或语言包，无 Google Translate 入口。完整词库会增加安装包和本机占用。

检查旧笔记、签名、框选旋转、书签、阅读进度；继续阅读小组件、导出 PDF 和本地备份应可用。
