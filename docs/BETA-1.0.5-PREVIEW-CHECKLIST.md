# 1.0.5-preview Beta 真机测试清单

目标设备：小米平板 9 Pro Max。先做本地备份，再覆盖安装，无需卸载。请记录问题发生的工具、页码、缩放程度及复现步骤。模拟器回归不能代替真实笔感与速度验收。

| 测试 | 操作与预期 |
| --- | --- |
| 覆盖升级 | 从 1.0.4-preview 检查更新或安装新 APK；主页和关于显示 1.0.5-preview / Beta，文档、批注、书签和阅读位置保留。 |
| 停笔拉直 | 用笔 / 铅笔 / 钢笔 / 荧光笔画近似直线，笔尖不离屏停约 0.65 秒，应变直；继续移动能调整终点，抬笔后一次撤销消除整笔。正常连续书写不应因短暂停顿被改线；短划、圈线和折线不应误拉直。 |
| 铅笔质感 | 新画轻重、快慢、长短笔迹，再放大看端点和笔身；不应再有明显离散圆点，纹理应细淡。旧笔迹外观保持，保存重开与 PDF 导出一致。 |
| 框选旋转 | 组合框选手写、圆 / 矩形、图片或签名，拖动旋转手柄，再移动 / 缩放；撤销、重做、保存重开和导出后方向与位置一致。靠页面边缘也能操作。 |
| 橡皮回归 | 旋转形状或图片后，在其实际显示位置擦除；不应擦到原来未旋转的位置。笔、橡皮切换正常。 |
| 工具悬停 | 触控笔悬停并点击每个顶栏工具，长按、移出后再点击；不应出现橙色矩形或残留色块，选中态仍清楚。 |
| 417 页课件 | 侧栏快速滚到第 17–20、35–37 页，再跳远页并返回；可见缩略图应补齐，不长期只剩页码。放大正文时重复操作，记录仍慢的页码和秒数。 |
| PDF 缩放 | 连续双指放大、拖动、换页，单页与双页分别测；可见页应先出现内容，再恢复高清，不应持续空白或卡住。 |
| 动画 | 重复打开文档、返回书库、开关侧栏、笔菜单和更多菜单；轻短连续，无黑闪、重影或不能点击。快速反复操作不堆叠；系统关闭动画后应直接切换。 |
| 离线与稳定性 | 飞行模式查单词、词组，书写 / 签名 / 导出；无下载翻译包提示。横竖屏切换、退出重开和连续使用几分钟，无数据丢失或崩溃。 |
