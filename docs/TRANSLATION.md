# 本地词典与词组

Annota 的阅读、书写、查词必须安装后即可离线使用。所有词典内容和更新随 APK 一起交付，不另行下载模型、不依赖 Google 或其他在线翻译服务。

1.0.4-preview Beta已移除旧 Beta 的 ML Kit 翻译链路、模型下载和归属界面，保留随包的英汉、汉英以及 942 条原创词组 / 术语、682 个别名。长选区完整保留，但不提供整句机器翻译；未收录时不伪造译文。

今后若提供整句翻译，所需模型、词表、推理组件和许可必须可随 APK 合法分发，并在首次启动断网环境验证通过。不能以“首次下载后离线”替代纯本地原则。应用更新与意见反馈仍仅在用户主动操作时联网。

1.0.6-preview 收录全部有中文释义的 ECDICT 记录：英汉 771,180 条（含 942 条原创词组），汉英 126,272 条。未整体匹配的英文词组按最长有据片段查询，保留词边界和源词形；界面明确标为“分段释义”，未知片段显示“未收录”。不拼装成看似完整的句子译文。
