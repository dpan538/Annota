# 1.0.4-preview Beta 验收记录

维护者已授权将本轮以 1.0.4-preview Beta 发布，暂不作为 1.1.0 正式版交付。versionCode 16，沿用已有证书。

- 移除 Google ML Kit 及句子翻译 / 模型下载入口。词库全部随 APK，首次使用即可离线。长选区保留并提示选取单词或词组。
- 直尺双指旋转增益降为 0.55；接近水平 2.5° 内自动吸附，超过 5° 脱离，支持正反方向水平。双指相距不足 48 dp 时暂停旋转，防止近距离角度抖动；跨 ±180° 不突跳。没有新增设置项。
- 应用主页、关于和更新页明确显示 Beta；按此前授权使用默认更新入口提供该测试版。

真机手感与实际课件性能由维护者按[清单](BETA-1.0.4-PREVIEW-CHECKLIST.md)验证；模拟器测试不代表真机验收。

## 批注与渲染

- 在图形和手形工具之间加入框选；支持新增笔迹、荧光笔、形状、图片及签名整体移动和等比缩放，完成一次操作对应一步撤销。PDF 原文不属于可编辑批注。
- 选词改为优先命中最近词框，并增加屏幕坐标下的点击容差与选区手柄范围。
- 修正荧光笔图标的笔身、笔尖与底线连接。
- PDF 渲染复用最多两个文档句柄，避免缩略图和放大分块反复解析同一文件；缓存按运行时堆预算增加，仍响应内存回收。
- 缩略图完成通知切换到主线程，通知所有订阅视图；首个视图退出屏幕后不再阻塞替代视图刷新。

## 内部候选历史验证

- Debug、测试 APK、Release 构建与 Android Lint 通过。
- 专用 API 36 ARM64 模拟器断网运行 102 项回归通过，见 `android/verification/offline-ruler-1.1.0/regression.txt`；另有 12 项 Python 词库回归通过。
- 离线首次安装测试从 APK 重新安装词库，验证英汉、汉英、词组查询，不依赖已下载模型。后续仅补充署名文案清理与打包检查，最终候选另跑 2 项断网回归通过，见 `final-offline-check.txt`。
- 旧 Beta 14 → 初始 1.1.0 候选 15 的覆盖安装保持测试文档和设置，见 `upgrade-and-package.json`；该记录保留初始候选哈希，不冒充最终包验收。
- 417 页合成 PDF 验证渲染句柄复用；尚未对用户实际课件做真机速度测量。新框选、图标和直尺手感仍需目标设备测试。

最终候选的包身份、签名、词库哈希、翻译 SDK / 下载资源扫描见 `android/verification/offline-ruler-1.1.0/final-package.json`。这些 1.1.0 路径仅为内部候选历史记录，未发布 1.1.0。

## 1.0.4-preview 发布验证

- 内部候选（15）→ 本 Beta（16）覆盖安装前后，测试文档、笔迹、书签和设置快照一致。既有 Beta（14）→ 候选（15）的验证为单独历史记录，没有将它标成直接 14 → 16 测试。
