# 1.0.7-preview · Beta 真机测试清单

覆盖安装后确认版本为 1.0.7-preview / Beta，不需要卸载。建议先做本地备份。

1. **打开与退出 PDF**：连续打开论文和大课件，再返回书库。应是较慢的短距离位移和轻微缩放，不再左右飞过整屏。检查闪白、突跳、文字重影和动画结束后模糊。
2. **中断过渡**：快速返回再打开；目录展开一半反向关闭。确认最终状态正确、可立即操作；系统关闭动画时立即切换。
3. **词典语境**：在云资源段落选择 `scalable and measured`，应分别偏向“可扩展的”和“可计量的”。点击 measured 片段后仍保留该语境；手动输入 `measured response` 时应采用日常含义。
4. **缩写**：对比 `IT`、`it`、`It`；测试 `CPU`、`VMs`、`DNS`，以及网络地址 / 知识产权段落中的 `IP`。无上下文的 IP 应保留多个候选。飞行模式仍可查询。查完 `measured` 后直接点击相邻 `IT`，应切换到新词而非重复旧词。
5. **右侧工具栏**：检查新增页、阅读、字典、更多四个图标与状态栏右端的视觉对齐；横竖屏以及三档按钮尺寸均不裁切、不遮挡。
6. **保留资料**：旧文档、批注、签名、书签、阅读位置仍在。铅笔、框选旋转、导出与本地备份保持可用。

请特别反馈动画速度与柔和程度，并附可重复步骤；无需提供私人文档。
