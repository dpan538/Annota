Original features

Each feature page states the problem, mechanism, measurable evidence, verification scope and limitations. These are engineering documents, not marketing claims.

Contact-Intent Edge Guard

接触意图边缘防误退出 · preview

A forearm resting on the screen edge no longer exits the reader: contacts are classified, edge gestures are excluded only while the pen or limb is active, and the first accidental back is deferred.

Ink Transaction Ledger

笔迹事务账本 · preview

Pen-up no longer serializes the whole book on the UI thread: a per-book append-only binary ledger records each stroke, and a single whole-book snapshot is written asynchronously.

Stroke Continuity Reconstruction

笔画连续性重建 · preview

Short input gaps inside one stroke are bridged with a curvature-constrained cubic Hermite, never across a pen lift and never into the future.

Ink-Flow Dynamics (inkVersion 6)

墨流动力学（inkVersion 6） · preview

A fixed-step continuous-time model of ink reservoir, flow, paper absorption and nib friction drives the width of new fountain-pen strokes, keeping connected strokes joined and giving slow writing more weight.

Predict–Reconcile Ink Compositor

预测-校正墨迹合成器 · preview

A self-written short-horizon predictor draws a confidence-weighted tail for the active stroke, then reconciles it when the real sample arrives; predictions never enter saved ink or PDF export.

Page-Picture Ink Cache

按页笔迹 Picture 缓存 · preview

Completed page ink is recorded once as a page-space Picture and replayed as one canvas op per frame; steady-state writing frames are 2.0–2.9× cheaper with zero changed pixels.

Offline Context Dictionary

离线上下文词典 · preview

A fully offline English–Chinese dictionary with an author abbreviation layer, initialism index, numeric-short-form recognition and a conservative OEWN domain prior for context sense selection.
