# 文档搜索与导航验收（0.1.9-dev）

## 实际演示

演示文档使用应用内原始《Attention Is All You Need》，包含原页阅读、全文搜索、选词复制、上下文查词、页书签与缩略图导航。`navigation-paper-*.png` 是该文档的原生截图；合成双栏、旋转和大结果集只用于边界回归。

阅读模式顶栏中间留空，所有控制在左右两侧。右侧笔图标恢复批注，不附加「批注」文字；原始 / 柔和 / 清晰三个预设放在右侧「更多 → 阅读显示」。选词浮层只保留「复制｜查词」文字按钮，跟随选区位置，无图标、无背景遮罩。

## 用户操作

- 「更多 → 文内搜索」或现有导航侧栏的搜索入口：输入词语/短句，原页显示匹配高亮，前后按钮循环切换。搜索期间暂时只读；关闭侧栏恢复进入前的视口、缩放和笔型。旋转保留查询、结果序号与返回位置。
- 长按文字，拖动首尾手柄可扩展同页跨行选区；触摸拖动显示放大镜。常规双栏按几何阅读流隔离，避免顺带选入另一栏。
- 左侧原页面入口：页面 / 目录 / 书签共用一个侧栏。书签按页 ID 保存，重排后跟随原页；不写入笔迹历史，复制与本地备份/恢复会重新映射页 ID。
- 内置 PDF 目录和文内链接跳转后，临时「返回原处」控件恢复之前的位置。最多保留 20 个返回点。

## 实现边界

搜索直接读取源 PDF 文字层，规范化大小写与 Unicode，支持跨行短句、行末英文断词和连续中文。后台每个任务独立打开并关闭解析器，输入变化取消过期任务，逐页返回结果，最多 1,000 条；到达上限显示加号。扫描 PDF 没有文字层时不提供 OCR。原文件、导出和应用笔迹颜色不变。

列识别依据重复栏间空隙，不是语义重建；任意复杂表格/版面和跨页选区不在支持承诺内。目录最多 2,000 项 / 24 层，文内链接每页最多 500 个；支持直接/命名 GoTo 目的地及源页旋转、裁切坐标，已删除目标不会跳到错误页。外部网页和可执行 PDF 动作不启动。
