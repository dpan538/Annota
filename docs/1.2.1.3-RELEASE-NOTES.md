## 修复/新增

| 项目 | 内容 |
| --- | --- |
| 文本框点击消失 | 编辑器延迟到触摸序列结束后打开，首次 outside-touch 保护；真实窗口测试确认弹窗保持并获得焦点 |
| 长按文本框 | 仅“复制 / 删除” |

| 文字工具菜单 | 再次点击文字图标：字号档位 + 颜色 |
| 翻译归一化 | 全大写普通词转小写，缩写 API/HA/K8s 等保留；不再出现 `三REE`、`FOUR` 残留 |
| 专业术语层 | 1,157 条，7 个领域，优先展示术语卡；术语同时保护译文；schema 7，+4.0MB |
