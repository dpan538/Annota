# 1.0.7-preview · Beta

versionCode **19**，沿用既有安装证书。默认更新检查提供本 Beta；不是正式稳定版，最近正式版仍为 1.0.2。

## 文件过渡

打开 / 返回不再横跨整块平板屏幕。改为 **320 ms** 的短距离垂直位移（20 dp）、轻微缩放（约 1.5%）及旧画面的辅助透明度变化，使用缓动曲线让起停更柔和。实时内容始终不透明；新首屏准备就绪后开始过渡，等待有上限。动画期间继续复用已有渲染缓存。

目录展开以 320 ms 完成左侧面板与右侧阅读区宽度同步变化，不用淡入淡出替代布局动画。中途返回、取消、系统关闭动画都要恢复位移和缩放并释放快照。

## 语境与缩写

- 保留输入 / 选区的大小写，包括分段释义中的 `IT`、`CPU`、`VMs`。小写 `it` 和句首 `It` 继续作为普通单词处理。
- 随 APK 加入经 NIST 术语资料核对的 **9 个缩写、12 个义项**，中文为 Annota 编写的简释。保留 `IP` 的网际协议 / 知识产权 / 外壳防护等级等歧义，证据不足时展示候选，证据明确时优先对应义项。
- `scalable` 在系统资源语境优先“可扩展的”；`measured` 在云资源计量语境优先“可计量的”，实验测量与日常“慎重的”用法分开。
- 分段查词保留选区内外的上下文，点击片段继续传递语境；手动编辑查询时清除旧语境，避免污染新查询。

这些是有限的离线词法与语境规则，不是通用整句翻译模型。全量 ECDICT / CC-CEDICT 保留；本轮补充不是整个 NIST 词典的导入。所有内容随 APK 提供，无额外下载或联网查词。来源与范围见[术语补充说明](../design/dictionary/TECHNICAL-TERMS.md)。

另修复了选区手柄的扩大热区截获相邻短词点击的问题：轻点相邻文字选择新词，拖动手柄调整原选区。

## 对齐与文档

阅读工具栏右侧操作整体增加 16 个界面设计单位的边距，与顶部状态内容的留白更接近；系统状态图标由系统绘制，仍需目标机确认视觉对齐。左右方向使用布局相对边距。

中英文 README 移除 Hero 大图，保留功能截图区；Android、Beta、Stable、许可、离线、本地存储、免账号和目标设备采用不同颜色标签。
