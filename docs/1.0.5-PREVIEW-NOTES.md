# 1.0.5-preview Beta 验收记录

本轮为 **1.0.5-preview Beta**（versionCode 17），不是正式稳定版。沿用已有证书，可覆盖升级；最近正式版仍为 1.0.2。按维护者此前授权，默认更新检查提供本 Beta，下载和安装仍需用户确认。

## 书写与批注

- 画近似直线后保持笔尖约 650 ms，自动拉直；抬笔前可继续调整终点。短划、弯折、回环与往返涂画不触发；操作完成只记一次撤销。
- 换工具、跳页、改变布局或取消输入时清除待处理笔迹及停笔计时，避免旧页落下意外笔迹。
- 框选新增旋转手柄，覆盖新增笔迹、形状、图片及签名；原 PDF 内容不编辑。形状与图片保留局部尺寸，笔迹保留已绘制的宽度，角度随本地记录与 PDF 导出保存。
- 新铅笔移除均匀灰底，使用透明石墨覆盖；压力控制浓淡，重复涂画累积颜色，读取笔倾角扩大阴影笔触，并忽略原地重复压力采样产生的圆点。既有版本的笔迹保留原绘制方式，不擅自改变用户保存的笔记。

## 铅笔设计依据与边界

参考 Apple [Introducing PencilKit](https://developer.apple.com/videos/play/wwdc2019/221/) 的压力、倾角与笔触响应，以及 [PencilKit 笔迹数据模型](https://developer.apple.com/videos/play/wwdc2020/10148/) 中逐点尺寸和透明度的设计。公开资料未给出完整铅笔着色器，本项目独立实现程序化纸纹与石墨覆盖，不声称复刻 Apple 算法。

纹理固定在文档坐标，放大不随机闪烁；倾角缺失时保留直立笔触。PDF 导出只将新铅笔纹理以 576 dpi 透明分块嵌入，原 PDF 与其他矢量批注不整页栅格化。代价是大量铅笔阴影会增大导出文件与导出耗时。

## 渲染与交互

- 修复侧栏行在离屏时记录空白绘制结果、滚入可见区域后仍长期留白的问题；用真实拖动和屏幕像素检查验证，不再只检查缓存命中。
- 缩略图独立使用 PDF 渲染池，避免正文高清分块阻塞侧栏；离屏排队任务及时取消。
- 当前页变化不重建整个侧栏；正文先补齐所有可见页底图，再处理高清分块。
- 工具不再使用系统列表选择背景，消除部分系统的橙色矩形；圆角悬停、按压和键盘焦点保留可辨识反馈。
- 文档打开 / 返回使用 180 ms 线性淡出旧画面；过渡快照最长边限制在 1440 px，快速切换与窗口退出时回收。侧栏及浮层使用短过渡，系统关闭动画时直接切换。
- 无新增偏好选项；词典继续完全随 APK 交付，不含 Google 翻译 SDK、模型下载或联网翻译入口。

## 验证范围

仪器测试运行于专用 Android 16 / API 36 ARM64 模拟器；目标小米平板的笔感、系统悬停和真实帧率仍按[真机清单](BETA-1.0.5-PREVIEW-CHECKLIST.md)验证。使用维护者提供的 417 页实际课件复现渲染问题，课件和内容截图不进入仓库；只保留匿名测量。

1.0.4-preview（16）→ 初始 1.0.5-preview（17）同签名覆盖安装，文档、笔迹、书签、阅读位置和设置快照一致。证据见 `android/verification/preview-1.0.5/upgrade-and-package.json`。后续修复后的最终包验证单独记录。

为了让已有 1.0.2 客户端的 `/releases/latest` 发现此次更新，GitHub Release 使用 Latest 与 `prerelease=false` 元数据；应用、标题及文档始终标注 Beta，该通道兼容方式不代表正式稳定验收。

## 最终签名包验证

- 最终 APK：`Annota-1.0.5-preview.apk`，77,028,973 字节；SHA-256：`bb6489456193edf05ced7753b8baf815b494b0925991fdbb253c143fb6a1e0d0`。
- 117 项 Android 仪器回归：最终包首轮 116 项通过、1 项动画采样检查失败；修正测试采样后单独复核通过（详见日志）。包含实际 417 页课件的拖动、屏幕非空检查；Wi-Fi / 移动网络关闭。12 项词库回归、Debug / AndroidTest / 签名 Release 构建及 Lint 通过。
- 覆盖停笔期间抖动、取消和跳页，框选混合批注旋转、保存、撤销 / 重做和真实 PDF 导出像素；阅读、选词、签名、缓存释放等原有功能回归通过。
- 实际 MainActivity 的文档卡片打开 / 返回采集到单调变化的过渡帧；快速往返三次不残留，系统关闭动画时无中间帧。这是模拟器功能验证，不是目标设备帧率结论。
- 铅笔视觉对照来自实际 InkRenderer 的 4 倍缩放输出；对比透纸颗粒、轻重压、压力渐变及倾斜叠画，旧笔迹保持。截图只包含合成笔迹，未公开私人课件。
- 早期触控检查曾受模拟器 System UI 无响应弹窗拦截；恢复环境并修正测试等待后通过。最终包回归中，整屏软件绘制的动画采样自身造成过载、漏采中间帧；采样改为同一工具栏坐标区域，观察窗口从 500 ms 延长到 1000 ms 以覆盖首帧布局与结束帧；中间帧、单调变化与完成态断言保留，单独复核 4 项通过。应用动画参数未因测试调整。
