# 极简纯阅读验收（0.1.8-dev）

本轮只增加一个可感知的阅读入口与三个显示预设。手形仍是批注工作区内的浏览工具，纯阅读是独立只读状态。没有新增亮度、裁边、重排或第二套触摸偏好。

## 用户操作

1. 点顶栏书本进入纯阅读，批注和插页入口收起，保留页面导航、词典与更多。
2. 中央「阅读 · 柔和」小菜单只含原始、柔和、清晰三个横向纸色 / Aa 预览卡，选中项用细边框和勾选标记；点外部收起，不加重复标题或关闭行。柔和使用暖纸色和稍浅墨色；清晰仅小幅增强对比度。
3. 单击正文隐藏或显示顶栏，长按文字仍可复制和离线查词；词典仍避让实际软键盘。
4. 点「批注」回到原笔型、颜色、粗细和尺子状态。模式及预设按文档记住，其他文档独立。

原始预设不加滤镜。显示处理复用已有原 PDF 渲染分块，不重新打开文件、不清空缓存、不改变缩放或平移。隐藏顶栏采用保留布局的方式，避免正文跳动。

## 只读和颜色边界

除隐藏编辑入口外，绘制、笔尾/侧键临时橡皮、系统笔按键、两/三指撤销、插页、缩略图编辑和延迟返回的图片插入都有只读拦截。进入时取消尚未提交的笔迹并回滚尚未提交的擦除。导航、查词、收藏、导出仍可使用。

滤镜只作用于页面显示，不重写源 PDF、页序或应用矢量笔迹，导出使用原颜色。PDF 文字和内嵌图片一起变化，不冒称只增强文字；彩色图、灰轴和小注释均纳入检查。黑底笔记不套白纸变换。原始显示及退出后的页面像素还原由测试验证。

## 验证

最终 APK 通过 63 项原生回归，无跳过；lint 0 errors / 78 warnings。另完成独立视觉流程和 420 dpi 阅读模式布局/实际键盘流程。阅读模式键盘用 68 档，三卡菜单覆盖全部三档；批注工作区另在 76 档运行完整大键盘流程，分开记录条件。

构建身份、源文件及测试哈希见 `android/verification/reading-build.json`。原始日志为 `reading-instrumentation-api36.txt`，额外视觉流程为 `reading-regression-visual-api36.txt`，420 dpi 的最大按键/真实软键盘为 `reading-large-*-api36.txt`。PNG 均为未经拼接、滤镜或缩放的原生屏幕截图。

新增六项覆盖（包括三卡完整可见、仅一项选中及浅面板比例）：三个预设像素/灰阶/彩色区分；笔、橡皮、侧键、多指手势只读；按文档重开及批注参数恢复；PDF 分块驻留、视口、源文件不变和原始像素还原；60/68/76 横竖屏、中英文和三个选项；隐藏顶栏后长按词典及实际 IME 内容可见。专项夹具是自制可检索双页 PDF，含小字、公式样式文本、细灰轴和三色图，不将其当作所有论文类型的覆盖。

最初独立视图的异步渲染等待未完成，原因是测试视图未附着窗口、无法投递回调。测试改用真实 Activity 已附着阅读器；没有把该测试等待问题宣称为产品崩溃。完整回归同时发现按钮按下缩放的坐标被当作菜单锚点，造成参数切换时 1–2 px 微移；菜单现改用父容器中的固定布局坐标，原断言继续检查同一个弹窗的边界不变。字典单行 TextView 的 lineHeight 包含行间距，曾使完整显示的单行被测试误判；断言改为首行实际排版下边界，并核对原生截图，未降低首行可见要求。隐藏顶栏时切换为深色系统状态图标，保证浅色阅读背景下可读。

更新签名校验使用同证书 versionCode 10 / update-test-fixture，仅为未发布夹具。

所有自动测试限定专用 API 36 ARM64 模拟器；小米真机、实际笔及长期使用不在本轮通过结论内。旧 316 轮记录属于旧版本。

## 参考与取舍

- [BOOX PDF 调整说明](https://booxsupport.zendesk.com/hc/en-us/articles/25060274198036-Adjust-PDF-and-Similar)：参考显示预设与对比度调整的方向，本轮收敛为三项，不复制整套设置。
- [KOReader 官方手册](https://koreader.rocks/user_guide/)：PDF 对比度同时影响文字和图片，所以保留原始预设并检查灰轴和彩色内容。
- [BOOX 刷新设置](https://booxsupport.zendesk.com/hc/en-us/articles/10701492644372-Refresh-Settings)：水墨屏清残影的全刷与普通平板不同，本轮不引入全屏闪刷。

这些是本产品的实现取舍，不代表使用了厂商专有算法，也不承诺护眼或硬件延迟改善。
