# Annota 1.1.0 正式版

versionCode **20**。沿用既有签名，支持从 1.0.2 正式版以及 1.0.3–1.0.7 测试版覆盖升级。GitHub Latest 与应用默认更新入口提供本正式版。

## 本轮调整

- **文件进入 / 返回**：过渡由 320 ms 延长到 460 ms，使用短距离垂直位移与轻微缩放；旧画面静止退出，新旧内容分阶段交接，减少叠字残影。目录继续使用侧栏展开与阅读区宽度同步变化。系统关闭动画时直接切换。
- **菜单重复点击**：更多、图形、字典、笔与橡皮浮层再次点击入口可收起，再次点击可重新打开。处理系统 outside 事件先关闭弹窗而导致按钮又打开它的情况。
- **通用离线检索**：精确命中的派生词继续关联来源原词，不再让一个窄义项遮住整个原词；原释义分成简短条目，后续义项按需展开。独立加入 WordNet / Chinese Open WordNet 词义索引和不规则词形，用有限局部证据排序，保留其他候选。

以单词查词为主，多词选区继续提供有标识的分段释义。所有数据随 APK 安装，不增加联网词典、语言包下载、Google 翻译入口或在线模型。词库覆盖与中文对应存在边界，不能把局部词义排序理解为完整句子翻译。

## 真机重点复核

1. 从当前版本覆盖升级，确认显示 **1.1.0 · 正式版**，原文档与笔迹保留。
2. 连续打开 / 返回 PDF，检查速度、拖影和停顿；快速反向操作及关闭系统动画后无残留。
3. 打开目录再收起，确认正文连续缩放、缩略图及时出现、阅读位置不跳变。
4. 对更多、图形、字典、笔、橡皮连续点击两次：打开后收起，第三次正常再打开；菜单外点击与返回键也正常。
5. 飞行模式下查询 `scaling`、`related`、`mice`、`written`，再从自己的不同学科文档随机选词；展开其他义项，确认不限于示例课件。
6. 检查旧批注、铅笔纹理、框选变换及 PDF 导出仍正常。
