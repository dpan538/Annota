# 离线上下文与简短释义

2026-10-21，0.1.6-dev 本地候选的继续修正。

选词查词携带同栏、当前句子附近的短窗口。按文字坐标排除邻栏，在句末截断，最多各取前后 22 个词；不拿整篇论文标题代替局部语境，不上传或持久化这段文本。手动编辑查询后清除旧选区并停止复用旧语境，即使随后输回同一个词也不自动重挂。

默认只显示 1–2 条简释；其余义项放入“更多释义”，同一面板内展开/收起，不重建阅读器。每条优先保留完整短译词，剔除冗长用例，中文最多 20 字（另加省略号）、英文最多 68 字符。展开后的义项也受此限制；不再默认展示旧词库中的 DOS 命令说明等长段落。

上下文匹配完全离线：优先查词库已有的相邻短语，结合词性线索及 21 个常见歧义词的原创短义和搭配规则。训练/测试集、集合、设置、日落；银行/河岸；模型/模特儿；细胞/电池等分别处理。空格合并后的同形词不作为短语匹配证据，避免把动词 `set up` 误当成名词 `setup`。没有明确证据或多个规则同分时保留备选，不标注“当前语境”。

这是有明确覆盖边界的本地词典匹配，不是通用语义模型：规则外的词使用词库短语/明确词性提示或精简回退，不能保证所有词、复杂隐喻或所有 PDF 排版都消歧正确。原始 SQLite 释义不删除，查词不新增联网、模型下载、OCR 或整句翻译。

验证包括六项数据/上下文用例和一项原生界面流程：

- 同一词随句子改变含义；语境冲突、缺失、手动改词时不强判；规则表外的动词词性提示；简释与更多义项长度约束；双栏和句界排除。
- 真正导入一份三句/双栏 PDF，原生触摸选取 `training set`、日落句中的 `set`、河岸句中的 `bank`，经过选区菜单进入词典，分别显示“数据集”“日落”“河岸”。
- 展开与收起保持同一 PopupWindow/ReaderView；手动改为 `bank` 显示两条短备选并清除旧高亮，输回 `set` 不复用旧语境。
