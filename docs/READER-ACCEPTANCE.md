# 阅读器设计与离线闭环验收

2026-10-21。本轮以原生开发包验证；API 36 ARM64 模拟器结果不代表小米真机或生产发布验收。

## 已确定的设计

- 正式启动标识沿用原版 Outfit 600：黑色字母、钴蓝 t、圆角白底、字形边界居中。首页同字形全部黑色。铅笔 t 尝试已放弃，不进入正式资源。
- 书库使用文档真实第一页；横版指南保持横版。竖版 PDF 的封面仅去除外围白边后按卡片宽度显示，超出卡片下缘的内容在预览中裁切；源文档不改动。导入 PDF 自动使用第一页。
- 阅读画布底部没有页码或操作条。系统导航区在阅读时隐藏，并去掉其主题色带；系统边缘手势可临时唤回。页码和页面操作放在顶部入口内。
- 新建笔记与新增纸页提供空白 / 点阵 / 格子 / 横线，白 / 灰 / 黑。已有笔记页面从顶部页面入口长按页面，再选纸张模板和底色。更换模板不清除笔迹，可撤销；原 PDF 不覆盖原始页面底色。

## 初始化规则

只有全新书库得到 11 页论文和五页指南。任一历史初始化标记都视为已完成：重启、升级、仅剩一个文件、移入废纸篓或彻底删除，都不再次补充。旧的仅指南开发版也不再追加论文。两个资源都校验完成后才提交书库事务；复制失败可重试，不出现半套索引。

## 内存策略

采用设备正常 `memoryClass` 和 `isLowRamDevice` 计算预算，未申请 largeHeap。各预算单位为 MiB：

| 缓存 | 正常设备上限 | 低内存设备最低预算 |
| --- | --- | --- |
| PDF 页面位图 | 32 | 4 |
| 插入图片 | 12 | 2 |
| 书库/页面封面（每个活动视图） | 8 | 1 |
| 文字坐标 | 4 | 1 |

小堆设备预算相应缩小；文字坐标按条目估算计费，位图按实际 allocationByteCount 计费。解码尺寸再按预算限制；PDFBox 使用 24 MiB 混合内存与磁盘临时文件。首页流式读取每份笔记的首页元数据，不加载全书笔迹；打开文档和导出/备份时读取完整状态。封面单线程、队列最多 6 项，阅读器 2 个线程、排队最多 4 项。页面列表只创建可见行。

后台/内存回调会清空可重建缓存并作废旧请求；前台再按需加载。缓存回收不修改笔迹、页序、背景或阅读进度。单页文字超过本机文字缓存限额时提示限制，仍能阅读与批注。上述预算是缓存上限，不是整个进程 PSS 保证，GPU、PDF 引擎和当前文档也占内存。

## 可重跑的验证

原生回归涵盖 12 种纸张的保存/恢复与撤销、真实封面方向与白边、十页十万点书库预览与完整备份、底部无页码，以及实际挂载阅读器缓存回收/重建和系统导航隐藏。既有 PDF、选字、输入、词典、导出、备份、更新签名回归一并保留。

实际系统流程脚本 `android/scripts/verify-reader-flow.py` 只允许专用模拟器，必须显式传 `--reset-test-library`；它会清除测试书库，禁止对用户平板使用。

```sh
cd android
python3 scripts/verify-reader-flow.py \
  --adb "$ANDROID_HOME/platform-tools/adb" \
  --apk app/build/outputs/apk/debug/app-debug.apk \
  --upgrade-apk /path/to/same-key-higher-version-fixture.apk \
  --reset-test-library
```

流程：断网首次两文件 → UI 新建黑底格子 → 真实输入笔迹 → 桌面后台与回收 → 强制停止/冷启动 → 系统保存 PDF → 删除两份样例 → 同签名覆盖升级 → 模拟器重启。状态与文件摘要记录在 `android/verification/reader-polish-*`。测试夹具不是发布版。

2026-10-21 实跑全部通过。最终 0.1.3-dev (4) 的 24 项仪器测试无跳过，lint 0 errors / 54 warnings；本地反馈服务 5 项通过。实际升级夹具为同开发签名 0.1.4-update-fixture (5)。系统导出的单页 PDF 已独立重开、渲染核对。

挂载阅读器实测：页面缓存 10,141,600 bytes、文字估算 30,760 bytes，回收后均为 0；恢复后页面重新渲染且已存状态不变。UI 流程的前台 PSS 为 135,094 KiB，进入后台后为 135,496 KiB：该短样本没有显示整个进程 PSS 下降，不能据此声称系统立即归还全部内存。手工 `am send-trim-memory` 因 Android 进程状态被系统拒绝，本流程仍核对实际后台/恢复；内存回调清空与重建由上述实际 Activity 仪器测试单独验证。
