# Annota 1.2.0 正式版 — 本地词典检索升级

versionCode **22**。沿用原有安装证书，可从 1.1.1 正式版与更早版本覆盖升级。本版只改本地词典与检索；
阅读、批注、离线翻译和隐私边界不变。

## 修复

- **Wiktionary 伪义项**：Kaikki 的普通话译词有时挂在 `Translations` 等章节标题下，旧构建把它当作
  gloss 写入词义索引（1,786 条）。`cut` 的 `intj / rank 0 / “卡”` 曾被选为第一释义；`bra` 曾出现
  “左矢”。本版过滤这些章节标题、按实际保留的义项重新编号，并增加构建期固定的 `sense_order`；
  无上下文查 `cut` 首义恢复为「一份利润 / 切」，`bra` 只显示胸罩。词形与英文兜底数据不受影响。
- **混合语境不过度自信**：当人工规则提示两个主题冲突时（例如 “money deposit near the river … shore”），
  不再让词面重叠单独选出确定首义，保留两个候选。`bank` 的既有回归用例恢复通过。

## 新的开源词库

- **Chinese WordNet（CWN，Academia Sinica）** 4,913 synset / 8,069 中文 lemma。
- **OMW Wiktionary Mandarin** 12,130 synset / 19,079 中文 lemma。
- 两者经 PWN30 synset 与 CILI 对齐并入 `wordnet.sqlite`；合并后 50,639 synset / 95,221 条英中词义关联 /
  72,948 个英文词头（1.1.1 为 42,300 / 77,708 / 61,340）。
- **Open English WordNet 2025** 提供可经 CILI 对齐的英文释义与同义词；未对齐的 3,184 个
  `ili="in"` synset 不进入索引。中文等价仍来自 COW/CWN/Wiktionary。
- **Princeton WordNet 3.0** 提供英文词形与义项频率序（`index.sense` 的 sense_number，不是物理行序）。
- **OpenCC `TSCharacters.txt`** 4,148 条繁→简单字映射 → `zh-en.sqlite.variants`；繁体查询自动扩展为
  简体检索。未链接 OpenCC 运行时。
- **ECDICT 词频列**：构建期保留上游 `bnc`/`frq` 词频秩，用于建议与候选排序；不影响词条是否收录。
- **汉英库**：新增 3,529 个 CC-CEDICT 未收录的中文词条（英文释义来自对齐的 WordNet synset）。

所有仅构建期使用的源文件（OEWN 2025、CILI 映射、WordNet 3.0 派生表、OMW 中文字表、OpenCC 字表，
共 7 个 gzip、约 18 MB）放在 `design/dictionary/sources-build/`，不进入 APK；生成数据库仍可完全离线重建。
许可与署名随 APK 提供：CC BY 4.0（OEWN、CILI）、CWN 自定义许可、CC BY-SA 3.0（OMW Wiktionary）、
Apache 2.0（OpenCC）、WordNet 3.0 许可。

## 检索性能

- 持久只读 SQLite 连接；`Dictionary`/`WordNetDictionary` 不再每次查询 open/close。
- 查询与负结果 LRU 缓存（含语境签名），取消中的查询不写缓存。
- **Bloom 位图预筛**：1,316,131 个可检索 key，10 bit/key、7 次哈希（约 1.65 MB，实测假阳性 0.8%，
  抽样 500 个真实 key 零假阴性）；不存在的片段不再触发 SQL。位图缺失/损坏时自动降级。
- **Myers 位并行编辑距离**（保留相邻换位语义，与旧 DP 全量对拍），词频参与建议排序。
- 长选区分段：Bloom 预筛 + 持久连接 + 片段缓存。模拟器上 105 词 / 704 字符选区：
  首次约 163–243 ms、重复约 48–66 ms（优化前同用例 1,070–1,584 ms）。
- 繁简查询扩展与义项 `sense_order` 排序。

## 已知范围

- CWN 与 OMW Wiktionary 中文词义未经逐条人工校对；合并后的条目数与主词库不能相加。
- OEWN 只提供英文释义/同义词；CILI 对齐失败时保留 COW 原释义。
- 繁简扩展是逐字映射，不做词组级异体转换；一字多简时取 OpenCC 首个候选。
- 词频先验可能把常用词的拼写建议排在低频专业词之前；其他候选仍可展开。
- 语义重排、离线参考翻译的质量边界与 1.1.1 相同，不能视为已校验译文。
- 模拟器通过不等于 Xiaomi Pad 9 Pro Max 的手感、帧率或内存验收；本版仍需目标平板复核。

## 目标平板复核清单

1. 飞行模式首次查 `cut`、`bra`、`bank`：首义不含「卡 / 左矢」，混合语境不强行单义。
2. 输入繁体（如 `學習`、`電腦`）与对应简体，结果一致且条目可展开。
3. 漏拼 `recieve`、`adress`、`attnetion`：建议首项为常见正确词，响应无明显停顿。
4. 打开 PDF 后长按选择 100+ 词段落：分段释义出现时间、滚动与书写是否受影响；重复选择更快。
5. 连续查词与展开其他释义后返回批注：检查延迟、发热与内存；APK 覆盖安装正常。
6. 设置中关闭 / 开启「本地词典」：普通查词始终可用，语义重排恢复后不重复生成已缓存向量。
7. 深色 / 浅色、大号界面与键盘弹出时词典面板布局正常；重启设备后词库校验不阻塞书库入口。
8. 打开关于页「开源与词库许可」，确认新增 OEWN / CWN / OMW / CILI / OpenCC 署名可离线阅读。
