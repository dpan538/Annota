# Annota 1.2.2（正式版）

**状态：当前正式版（Latest）。** 取代 1.2.0。

- 版本：`1.2.2` / versionCode 29
- APK：`Annota-1.2.2.apk`（SHA-256 `6e7e0261c8cd45fa156f6f6843bd676c634d432b960054b773d61f130b788686`）
- 主题：移除文字输入功能；修复局部橡皮误删整笔。

## 变更

- 移除工具栏文字图标、文字工具和文字输入交互。已有文字标注仅保留数据/PDF 兼容，不再提供创建或编辑入口。
- 橡皮默认局部模式；切换整笔/局部立即生效（菜单关闭后重开显示当前选择）。
- 局部模式只切分橡皮路径命中的笔画区段，不再删除命中区域内的整笔；整笔模式只删除最近命中对象。
- 1.2.1.x 的离线词典、专业术语层、翻译归一化保留。

## 验证

- 签名正式 APK 上完整仪器化回归通过（API 36 ARM64 模拟器、离线、合成输入）。
- 真机笔尖、前臂接触、长按与真实 PDF 阅读器仍需验收。
