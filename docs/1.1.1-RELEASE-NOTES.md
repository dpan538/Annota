versionCode **21**。沿用原安装证书，已准备修复候选；按维护者要求暂不创建 GitHub Release、不上传 APK、不改变默认更新通道。用户当前可下载版本仍为 1.1.0。

## 修复

- **取词菜单滞留**：点击画布空白处、开始新的滑动、跳页或改变阅读布局时，选区与复制 / 查词菜单同步取消。保留选区手柄拖动和正常复制 / 查词；取消选区的一次点击不会顺带隐藏阅读工具栏。
- **阅读顶部空白占位**：工具栏使用向上收起与布局高度同步变化，收起后高度为零，正文填满释放的空间；轻点页面恢复。全程保持内容不透明，不用淡出替代位移。
- **阅读闲置收起**：约 5 秒无操作后收起。菜单、目录、选区或进行中的触摸会阻止自动收起；批注模式不自动隐藏。离开阅读页或进入后台时清理动画和计时，系统关闭动画时直接切换。

## 离线语言能力

- 新增 English Wiktionary 的普通话译义索引：48,077 个词头、61,076 个义项；其中相对 ECDICT 新增 11,054 个规范化词头。数据保持独立署名和 CC BY-SA 4.0 许可。
- 导入 LemmInflect 显式词形表，补充不规则和屈折词形；分段查询保留多义项，支持词组内部词形，并避免跨标点错误拼接。上下文候选按源释义与邻词的词形归一结果排序。
- 未整体收录的英文长词组 / 短句提供独立的“离线参考译文”，使用随 APK 内置的 OPUS-MT 量化模型、分词器与 ONNX CPU 推理。首次使用无需下载，无 Google 依赖、在线回退或遥测。
- 快速换词和关闭字典时取消旧翻译，避免旧结果覆盖新查询。模型闲置后释放；词典释义先显示。

短句仅支持英文→简体中文，最多 512 字符 / 64 个英文词（编码上限 128 token）；仍有歧义和专业词误译。词库规模与少量回归测试不代表翻译准确率。正式候选包仅含受支持平板所需的 ARM64 推理库；新增模型会增加 APK 与首次使用的存储占用。

所有词库与阅读内容仍在本机处理，本轮没有新增联网功能。详细来源与局限见 [调研记录](../design/dictionary/OFFLINE-LANGUAGE-111.md)。

## 验证与复核

验证证据保存在 [android/verification/stable-1.1.1](../android/verification/stable-1.1.1/)。模拟器测试不替代 Xiaomi Pad 9 Pro Max 真机手感验收。

待发布前的真机重点：

1. 取词后点空白处，复制 / 查词菜单与选区均消失，立即可以再次取词。
2. 取词后连续滑动或跳页，菜单不跟随滞留；选区手柄仍可拖动，复制和查词仍可使用。
3. 阅读模式轻点页面或闲置约 5 秒，顶部栏上收且不留原高度的空白；再次轻点恢复。
4. 打开菜单、拖动选区及批注时，不发生意外自动收起；横竖屏、返回书库再打开文档均正常。

5. 飞行模式首次查 `abaci`、`analyses`、`outgrew` 及未见过的专业词；展开其他释义并检查原词。
6. 查询陌生英文短句，检查“离线参考译文”；不要只测试已给出的课件。快速改词、关面板后再开，旧译文不应覆盖新查询。
7. 连续查词后返回批注，检查延迟、发热和内存；确认大 APK 覆盖安装正常。专业译文仍需人工核对。
