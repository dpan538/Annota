# Annota 1.1.1 正式版

versionCode **21**。沿用原安装证书，本次作为正式版发布，保留旧正式版及 Preview 的覆盖升级路径。

## 修复

- **取词菜单滞留**：点击画布空白处、开始新的滑动、跳页或改变阅读布局时，选区与复制 / 查词菜单同步取消。保留选区手柄拖动和正常复制 / 查词；取消选区的一次点击不会顺带隐藏阅读工具栏。
- **阅读顶部空白占位**：工具栏使用向上收起与布局高度同步变化，收起后高度为零，正文填满释放的空间；轻点页面恢复。全程保持内容不透明，不用淡出替代位移。
- **阅读闲置收起**：约 5 秒无操作后收起。菜单、目录、选区或进行中的触摸会阻止自动收起；批注模式不自动隐藏。离开阅读页或进入后台时清理动画和计时，系统关闭动画时直接切换。

## 离线语言能力

- 新增 English Wiktionary 的普通话译义索引：48,077 个词头、61,076 个义项；其中相对 ECDICT 新增 11,054 个规范化词头。数据保持独立署名和 CC BY-SA 4.0 许可。
- 导入 LemmInflect 显式词形表，补充不规则和屈折词形；分段查询保留多义项，支持词组内部词形，并避免跨标点错误拼接。上下文候选按源释义与邻词的词形归一结果排序。
- 未整体收录的英文长词组 / 短句提供独立的“离线参考译文”，使用随 APK 内置的 OPUS-MT 量化模型、分词器与 ONNX CPU 推理。首次使用无需下载，无 Google 依赖、在线回退或遥测。
- 快速换词和关闭字典时取消旧翻译，避免旧结果覆盖新查询。参考翻译独立于词典释义显示。排队的旧查词任务丢弃，正在处理的长选区也能及时取消。
- 继续加入 192,058 个有完整英文释义的词头，中文检索无结果时明确标注“英文释义”；新增 338,228 个来源词形关系，复合词最多还原两处词形。统一 PDF 断行和连字符检索，精确索引先于拼写建议，不针对单份课件硬编码。
- 长选区保留完整分段查词；翻译超过单次容量时按完整句子处理，保留条件与否定从句，超限明确提示，不静默截断。
- 词义排序改为跨 Wiktionary / WordNet 候选统一比较，不再由各词库分别宣布最佳义项；保留中文相同但英文定义不同的候选。结合已收录词形、近邻距离、候选间区分度和释义长度，证据不足时保留默认顺序及其他释义。
- 否定 / 排除语境和明显词性冲突采用保守拒判；领域与动词提示只帮助排序，不当作已确认词义。自动扩展词组需要实质词组合，避免把农田语境的 `in the field` 强行解释成作战；用户主动查询完整词组仍可使用。
- 长选区拆分查词时隔离句号、问号、感叹号和分号边界；英文兜底释义也参与语境排序并完整保留。默认排序优先保留跨来源支持的释义，不被另一词库的首条记录无条件覆盖。

### 本地语境重排

- 内置 Apache-2.0 的 all-MiniLM-L6-v2 ARM64 int8 模型及 92,869 个释义向量，覆盖中文 WordNet/Wiktionary 候选。查询先检索候选、完成语境排序，再一次显示；首次未命中缓存显示短暂查询状态。失败、超限或证据不足时采用普通排序。
- 打开 PDF 后后台预热模型，优先当前已提取页面，同句选词共用向量。上下文向量按内容、模型和算法版本保存于本机，重新打开可复用；不因每次查词或关闭文档重复生成。更换选词取消旧任务，滚动与书写暂停后台预处理。
- 采用双线程 CPU 推理与前台优先队列；模型闲置后释放，向量缓存保留。语义相似度结合义项竞争、同义等价、词性及弱语境门禁，仍有误选和来源错误，不能当作准确率保证。
- 设置 → 关于 → 应用更新下方新增「本地词典」开关，默认开启。点击右侧状态可关闭向量优化，普通离线查词仍可使用，已有缓存保留。

参考翻译仅支持英文→简体中文，最多 1024 字符 / 160 个英文词；每次编码上限 128 token，超出时最多分成 8 个完整句子，总推理期限 30 秒。长单句仍可能超限；仍有歧义和专业词误译。未知单词不交给模型猜译，英文释义不算汉译。词库规模与少量回归测试不代表翻译准确率。正式候选包仅含受支持平板所需的 ARM64 推理库；新增数据与模型会增加 APK 和首次使用的存储占用。

所有词库与阅读内容仍在本机处理，本轮没有新增联网功能。详细来源与局限见 [调研记录](../design/dictionary/OFFLINE-LANGUAGE-111.md)。

## 验证与复核

本次签名 APK、核心回归与公开下载证据保存在 [release-1.1.1](../android/verification/release-1.1.1/)，向量与缓存专项见 [semantic-111](../android/verification/semantic-111/)。此前阶段的回归见 [stable-1.1.1](../android/verification/stable-1.1.1/)。模拟器测试不替代 Xiaomi Pad 9 Pro Max 真机手感验收。

本轮扩词与完整句分段证据另见 [dictionary-expansion-111](../android/verification/dictionary-expansion-111/)。

词义排序、反例与来源质量审计另见 [sense-ranking-111](../android/verification/sense-ranking-111/) 和[开源方法研究](../design/dictionary/RESEARCH-SENSE-RANKING.md)。匹配分数不是准确率；上游错译、缺失义项和复杂句法仍会影响结果，不宣称已解决通用词义消歧。

目标平板复核清单：

1. 取词后点空白处，复制 / 查词菜单与选区均消失，立即可以再次取词。
2. 取词后连续滑动或跳页，菜单不跟随滞留；选区手柄仍可拖动，复制和查词仍可使用。
3. 阅读模式轻点页面或闲置约 5 秒，顶部栏上收且不留原高度的空白；再次轻点恢复。
4. 打开菜单、拖动选区及批注时，不发生意外自动收起；横竖屏、返回书库再打开文档均正常。

5. 飞行模式首次查 `abaci`、`analyses`、`outgrew` 及未见过的专业词；展开其他释义并检查原词。
6. 查询陌生英文短句，检查“离线参考译文”；不要只测试已给出的课件。快速改词、关面板后再开，旧译文不应覆盖新查询。
7. 连续查词后返回批注，检查延迟、发热和内存；确认大 APK 覆盖安装正常。专业译文仍需人工核对。
8. 查询 `came across`、`dendritic cells`、`microarchitectures`，检查是否能回到原词；查询 `hosts file`、`pseudoreplication`，应明确显示完整英文释义。再查普通中文译义词，不能残留英文标签。
9. 选取陌生的多句短段落，核对末句没有丢失；过长单句应提示缩短选区。含缩写、数字、否定和条件的译文需逐句核对，不以有输出代替语义正确。
10. 对同一多义词换日常和专业语境，检查首义项及展开项；再用否定、混合话题和线索不足的句子，确认不强行指定一个解释。词典释义与独立参考译文分别核对。

11. 打开 PDF 后稍候，在飞行模式下连续查询同句不同词，再关闭重开；检查首次等待、后续响应和书写流畅度。设置中关闭 / 开启「本地词典」，确认普通查词始终可用。
