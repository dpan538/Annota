# 本地数据与联网边界

这是当前原生实现的联网与本地数据说明。阅读、批注与提交反馈无需用户账号。

## 本地

PDF、笔记、批注、图片、文件夹索引、阅读进度和设置保存在设备。没有账号、云空间或跨端同步。阅读、书写、英汉 / 汉英查词、语境词义排序和英文→简体中文参考翻译均在本机进行，不上传文档或查询。词库、词形索引、MiniLM 模型与词义向量、OPUS-MT 模型和分词器全部随 APK 提供，首次使用也无需联网下载。

当前原生工程已关闭应用云备份及设备迁移，提供系统保存的 PDF 导出与本地 .annota.zip 备份/合并恢复。卸载或清除应用数据可能删除私有文件；发版前需要明确提醒，并验证恢复流程。系统 IME 和系统服务的行为需独立确认，不能只凭应用不联网推断输入法不联网。

## 应用网络

只有用户主动检查 / 下载应用更新、提交反馈会使用应用网络功能。反馈通过 HTTPS 发送到 `annota-feedback-dpan538s-projects.vercel.app`（Vercel），服务端使用仅限本仓库 Issues 写入的凭据创建公开 GitHub Issue。GitHub 写入凭据不进入 APK、客户端日志或仓库。本地推理使用随包 ONNX Runtime，已关闭运行时遥测；不调用 Google 翻译或其他外部翻译服务，不含在线模型下载路径，没有远程字体或文档后台同步。

反馈只包含用户填写的正文、应用版本和随机请求标记。不会附带联系方式、笔记、PDF、截图、日志、设备标识或手写内容。反馈正文公开在 [GitHub Issues](https://github.com/dpan538/Annota/issues)，由维护者管理；服务端不记录反馈正文或凭据日志。Vercel/GitHub 作为网络服务会处理建立连接所需的网络元数据，适用其各自隐私规则。

只有服务收到 GitHub 的真实 Issue URL、客户端核对回执与本次请求身份后，才自动弹出“已收到反馈”并清空对应草稿；网络或服务失败会自动提示并保留内容。无需“检查提交结果”按钮。提交期间产生的新草稿不会被旧回执清除。

当前部署已就绪；生产接口已获用户授权公开，预览仍保留登录保护。实际 Android 非调试包自动创建真实 Issue 和成功提示已通过端到端验收。

## 纯本地词典

英汉、汉英、Wiktionary、WordNet、来源词形及英文释义库随 APK 安装，扩充通过应用更新交付。中文检索未命中时可显示明确标注的英文释义；英文长词组和短句可使用本地 OPUS-MT 参考翻译。未知单词不会交给翻译模型猜释义。参考译文和语境排序可能出错，不代表专业翻译或已确认词义。

MiniLM 在本机比较阅读语境与候选词义，正常查词在重排完成后显示释义；模型失败、超时或证据不足时保留普通词典结果。打开 PDF 约 600 毫秒后可在后台预处理当前已提取页面的语境窗口；不为此扫描整本文档。推理使用两条 CPU 线程，闲置约 180 秒后释放原生模型资源。

为避免重复计算，应用将语境的内容哈希及对应向量保存在私有 SQLite 缓存中，不另存原始语境正文。缓存属于阅读内容衍生数据，仍应视作本地私人数据。相同内容、模型和算法版本可跨启动复用；版本或内容变化后重新计算。模型释放或关闭语义功能不会删除既有缓存；卸载或清除应用数据会删除缓存，当前文档备份不包含它。

「设置 → 关于」的应用更新下方有默认开启的「本地词典」开关，只控制语义重排及后台预处理，关闭后普通离线查词仍可使用。旧 Beta 的 Google 下载与翻译流程已移除；当前语言能力没有运行时联网下载或在线回退。

## 桌面小组件

“继续阅读”仅在本机显示最近打开文档的标题与页码，点击恢复已保存的阅读位置；不联网、不定时轮询、不输出 PDF 缩略图。最近文档被删除或移入废纸篓时，入口回到书库。

## 权限

从其他应用打开 PDF 时，使用发送方临时授予的读取权限复制到应用私有存储；不申请全盘文件权限。网络状态权限用于反馈的离线提示。文件与照片按用户主动选择授予访问；导出使用系统保存界面。更新只在用户触发安装时请求相关系统授权。避免与这些流程无关的全盘文件读取、通讯录、位置或其他权限。
