# 本地数据与联网边界

这是当前原生实现的联网与本地数据说明。阅读、批注与提交反馈无需用户账号。

## 本地

PDF、笔记、批注、图片、文件夹索引、阅读进度和设置保存在设备。没有账号、云空间或跨端同步。阅读、书写和随包英汉/汉英单词、词组查询不上传内容。可选句子翻译的输入和译文也在设备上处理，联网边界见下。

当前原生工程已关闭应用云备份及设备迁移，提供系统保存的 PDF 导出与本地 .annota.zip 备份/合并恢复。卸载或清除应用数据可能删除私有文件；发版前需要明确提醒，并验证恢复流程。系统 IME 和系统服务的行为需独立确认，不能只凭应用不联网推断输入法不联网。

## 应用网络

更新、反馈以及用户主动启用的可选翻译功能会使用网络。反馈通过 HTTPS 发送到 `annota-feedback-dpan538s-projects.vercel.app`（Vercel），服务端使用仅限本仓库 Issues 写入的凭据创建公开 GitHub Issue。GitHub 写入凭据不进入 APK、客户端日志或仓库。基础阅读和查词不初始化翻译 SDK；没有远程字体或文档后台同步。可选翻译 SDK 的网络与指标行为单列如下。

反馈只包含用户填写的正文、应用版本和随机请求标记。不会附带联系方式、笔记、PDF、截图、日志、设备标识或手写内容。反馈正文公开在 [GitHub Issues](https://github.com/dpan538/Annota/issues)，由维护者管理；服务端不记录反馈正文或凭据日志。Vercel/GitHub 作为网络服务会处理建立连接所需的网络元数据，适用其各自隐私规则。

只有服务收到 GitHub 的真实 Issue URL、客户端核对回执与本次请求身份后，才自动弹出“已收到反馈”并清空对应草稿；网络或服务失败会自动提示并保留内容。无需“检查提交结果”按钮。提交期间产生的新草稿不会被旧回执清除。

当前部署已就绪；生产接口已获用户授权公开，预览仍保留登录保护。实际 Android 非调试包自动创建真实 Issue 和成功提示已通过端到端验收。

## 可选句子翻译

单词与已收录词组始终优先查询随包数据库。只有用户点击「使用 Google Translate 翻译」后，才初始化 Google ML Kit 并检查端侧翻译模型；不在应用启动或普通查词时初始化该 SDK。

首次使用若缺少模型，需要用户另行确认通过 Wi-Fi 下载约 30 MB 的翻译包。下载完成后可断网英汉互译；下载或翻译失败不影响原有词库。Google 声明输入文本和译文不会发送到服务器，翻译在设备上完成。模型和服务可用性取决于设备及网络环境。

ML Kit 可能联系 Google 下载模型、获取模型更新或兼容性信息，并发送 API 使用情况与性能指标。因此启用可选翻译后，不能把整个应用表述为「从不联网」或「没有任何 SDK 指标」。点击翻译及下载前，面板会说明这一边界；不启用时保持原有本地查词路径。下载任务由 SDK 管理，关闭面板不会保证取消已经开始的下载；卸载或清除应用数据会清除应用私有数据。

详见 [翻译说明与归属](TRANSLATION.md)、[ML Kit 条款和数据使用说明](https://developers.google.com/ml-kit/terms)。Annota 不提供在线文档翻译或上传 PDF 到翻译服务器的功能。

## 桌面小组件

“继续阅读”仅在本机显示最近打开文档的标题与页码，点击恢复已保存的阅读位置；不联网、不定时轮询、不输出 PDF 缩略图。最近文档被删除或移入废纸篓时，入口回到书库。

## 权限

从其他应用打开 PDF 时，使用发送方临时授予的读取权限复制到应用私有存储；不申请全盘文件权限。网络状态权限用于反馈的离线提示与可选翻译模型的下载条件检查。文件与照片按用户主动选择授予访问；导出使用系统保存界面。更新只在用户触发安装时请求相关系统授权。避免与这些流程无关的全盘文件读取、通讯录、位置或其他权限。
