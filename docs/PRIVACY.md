# 本地数据与联网边界

这是当前开发版的实现说明。正式发布前还需补齐实际反馈服务方、服务器区域与联系途径，并完成目标设备验收。

## 本地

PDF、笔记、批注、图片、文件夹索引、阅读进度和设置保存在设备。没有账号、云空间或跨端同步。阅读、书写和英汉/汉英查词不上传内容。

当前原生工程已关闭应用云备份及设备迁移，提供系统保存的 PDF 导出与本地 .annota.zip 备份/合并恢复。卸载或清除应用数据可能删除私有文件；发版前需要明确提醒，并验证恢复流程。系统 IME 和系统服务的行为需独立确认，不能只凭应用不联网推断输入法不联网。

## 应用网络

仅用户主动检查/下载更新，或点击提交反馈时使用网络。主动打开 GitHub 主页会由系统浏览器联网。没有自动遥测、分析 SDK、远程字体或默认后台同步。

反馈只发送用户输入的正文和选填联系方式。不自动附带笔记、PDF、截图或日志。发送失败保留草稿；只有真实成功回执才显示成功并清空。GitHub Issue 是公开区域，不应收集联系方式。

## 正式反馈服务上线前需写清楚

实际服务方、服务器区域、传输和保存方式、保留期限、联系方式删除途径、限流与最小安全日志规则。原生构建的 `feedbackEndpoint` 默认为空，设计配置为 `null`，不能宣称已经运行匿名反馈服务。

## 权限

文件与照片按用户主动选择授予访问；导出使用系统保存界面。更新只在用户触发安装时请求相关系统授权。避免与这些流程无关的全盘文件读取、通讯录、位置或其他权限。
