# 本地数据与联网边界

这是当前原生实现的联网与本地数据说明。阅读、批注与提交反馈无需用户账号。

## 本地

PDF、笔记、批注、图片、文件夹索引、阅读进度和设置保存在设备。没有账号、云空间或跨端同步。阅读、书写和英汉/汉英查词不上传内容。

当前原生工程已关闭应用云备份及设备迁移，提供系统保存的 PDF 导出与本地 .annota.zip 备份/合并恢复。卸载或清除应用数据可能删除私有文件；发版前需要明确提醒，并验证恢复流程。系统 IME 和系统服务的行为需独立确认，不能只凭应用不联网推断输入法不联网。

## 应用网络

仅用户主动检查/下载更新、点击提交反馈时使用网络。反馈通过 HTTPS 发送到 `annota-feedback-dpan538s-projects.vercel.app`（Vercel），服务端使用仅限本仓库 Issues 写入的凭据创建公开 GitHub Issue。GitHub 写入凭据不进入 APK、客户端日志或仓库。没有自动遥测、分析 SDK、远程字体或默认后台同步。

反馈只包含用户填写的正文、应用版本和随机请求标记。不会附带联系方式、笔记、PDF、截图、日志、设备标识或手写内容。反馈正文公开在 [GitHub Issues](https://github.com/dpan538/Annota/issues)，由维护者管理；服务端不记录反馈正文或凭据日志。Vercel/GitHub 作为网络服务会处理建立连接所需的网络元数据，适用其各自隐私规则。

只有服务收到 GitHub 的真实 Issue URL、客户端核对回执与本次请求身份后，才自动弹出“已收到反馈”并清空对应草稿；网络或服务失败会自动提示并保留内容。无需“检查提交结果”按钮。提交期间产生的新草稿不会被旧回执清除。

当前部署已就绪；生产接口已获用户授权公开，预览仍保留登录保护。实际 Android 非调试包自动创建真实 Issue 和成功提示已通过端到端验收。

## 桌面小组件

“继续阅读”仅在本机显示最近打开文档的标题与页码，点击恢复已保存的阅读位置；不联网、不定时轮询、不输出 PDF 缩略图。最近文档被删除或移入废纸篓时，入口回到书库。

## 权限

从其他应用打开 PDF 时，使用发送方临时授予的读取权限复制到应用私有存储；不申请全盘文件权限。网络状态权限只用于反馈的离线提示。文件与照片按用户主动选择授予访问；导出使用系统保存界面。更新只在用户触发安装时请求相关系统授权。避免与这些流程无关的全盘文件读取、通讯录、位置或其他权限。
