# Annota 1.0.2 正式版 · 手写签名与 PDF 兼容性

## 新增

- 阅读页「更多 → 手写签名」：签名画布支持手指和标准手写笔、撤销与清空。
- 放入文档后可以拖动、等比缩放，确认后作为一次可撤销的批注保存，随 PDF 导出和本地备份保留。

## 修复

- 不再因 PDF 禁止提取文字或整体修改而直接拒绝导入；允许批注的文件仍可签字，限制修改的文件只读打开。
- 保留已签名 PDF 的原始文件；加密文件解锁时使用独立阅读副本。
- 未改动时导出原始字节；添加批注后另存副本保留已有签名的外观，并明确提示原数字签名的验证效力不随副本保留。
- 书库数据库升级保留已有文档、笔迹和撤销历史。

## 安装与验证

- 版本号 **1.0.2 / 13**，非调试 Release，沿用 1.0.1 的安装证书，可覆盖升级。
- 附件包含 `Annota-1.0.2.apk`、`SHA256SUMS.txt`、`annota-update.json`；已有用户可通过「设置 → 关于」检查更新。
- 23 项 API 36 模拟器回归及独立原生触摸流程通过。新功能的模拟器结果不代替目标平板和具体文件的实际验证。
- 本次提供手写签名，不提供证书数字签名或证书信任验证。

## English

- Add handwritten signature capture, positioning, proportional resizing, undo and PDF export.
- Fix permission-based rejection of signed/restricted PDFs; preserve original bytes and open modification-restricted files read-only.
- Preserve visible signature appearances in annotated copies while clearly distinguishing them from the digitally signed original.
- Keep the existing application certificate and migrate library data without losing ink or undo history.
