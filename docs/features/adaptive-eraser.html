Sized Partial/Whole Eraser · 独立档位橡皮（局部/整笔）

Status: stable · version 1.2.2 · updated 2026-11-08 eraserstylusannotationUI

What it is. The eraser has its own four sizes, independent from the pen, and explicit partial or whole-stroke modes; whole mode removes only the nearest hit instead of wiping neighbouring glyphs.

Problem it solves

The old eraser radius was derived from the pen width and the default whole-stroke mode deleted any hit mark, so adjacent letters or one continuous multi-letter stroke disappeared together.

How it works

An eraserWidth preference is independent from penWidth and exposed as four size levels in the eraser popover. Partial mode splits only the intersected mark; whole mode ranks hit marks by actual centreline/box distance and removes only the nearest one. Text and shapes are atomic and are never split into fragments.

Difference from existing approaches

The visible eraser size is the actual hit radius, and whole-stroke deletion is scoped to the nearest object rather than every object inside a large radius.

  • Partial v6 fragments lose the previous-stroke seam state
  • Whole mode still removes an entire multi-letter mark by design
