Offline Context Dictionary · 离线上下文词典

Status: preview · version 1.2.1.2 · updated 2026-11-08 offlinedictionaryabbreviationcontextOEWN

What it is. A fully offline English–Chinese dictionary with an author abbreviation layer, initialism index, numeric-short-form recognition and a conservative OEWN domain prior for context sense selection.

Problem it solves

Offline dictionaries usually behave as a static word list: abbreviations such as CAP, RAM, k8s or i18n and context-dependent senses are missing or guessed without evidence.

How it works

A 128-entry authored abbreviation table, a 401,909-entry initialism index and numeric contraction rules share context-cue ranking. WordNet senses carry OEWN lexfile domain labels and a nine-domain prior runs only after weighted Lesk abstains, requiring at least two independent leading cues. Unknown acronyms expand only when the context matches a candidate.

Difference from existing approaches

The layer combines authored abbreviations, initialisms and a conservative domain prior while keeping abstention: no context means no forced acronym expansion and no arbitrary sense promotion.

Limitations

  • Domain labels are coarse lexfiles
  • Authored probes are not an accuracy benchmark
  • Reverse zh-en entries are machine-merged and not individually proofread
