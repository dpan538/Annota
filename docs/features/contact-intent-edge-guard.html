Contact-Intent Edge Guard · 接触意图边缘防误退出

Status: preview · version 1.2.1.2 · updated 2026-11-08 styluspalm rejectionsystem gesturetablet

What it is. A forearm resting on the screen edge no longer exits the reader: contacts are classified, edge gestures are excluded only while the pen or limb is active, and the first accidental back is deferred.

Problem it solves

On tablets the forearm often touches the left or right screen edge. Android turns that edge contact into the system back gesture before the app sees it, so the reader closes while writing.

How it works

ContactIntent classifies stylus / finger / limb from tool type, touch major/minor and edge distance. A limb contact is consumed instead of drawing, panning or tapping chrome. While the pen or a limb is active, narrow left/right strips are excluded from the system back gesture; the first back within 1.8 s of a limb contact is deferred once and a second deliberate back still leaves.

Difference from existing approaches

Most note apps only reject palms. This separates resting-limb intent from deliberate finger navigation, and uses temporary system-gesture exclusion as an actuator of that intent state rather than a static setting.

Limitations

  • 12 mm / 48 dp / 1.8 s thresholds need real-device calibration
  • During the guard window a deliberate first edge swipe is deferred once
