Editable Text Annotation Box · 可拖动/缩放文字输入框

Status: preview · version 1.2.1.2 · updated 2026-11-08 textannotationIMEPDFundo

What it is. A page-anchored text box can be created from the toolbar, moved and resized, opened with the system keyboard, persisted with undo, and exported to PDF with the same layout.

Problem it solves

Notes often need typed text next to handwriting, but a PDF annotation canvas usually only offers ink and images; typing requires leaving the page.

How it works

A Mark of tool text stores a box in page coordinates and its text. A toolbar Type icon creates a default box; tapping inside opens an EditText popup over the page, the IME edits live, and drag or corner handles move/resize the box. The same StaticLayout rule is used on screen and in a 4x lossless PDF raster so Chinese, wrapping and line breaks match. Text boxes participate in undo, ledger recovery, selection and the eraser as atomic objects.

Difference from existing approaches

The editor is anchored to the page-space box (not a separate dialog), so the writer sees the final typography in context; a single layout rule drives both screen and PDF instead of two approximations.

Limitations

  • Text PDF is rasterized (not selectable)
  • Text taller than the box is not clipped; the box can be enlarged
  • Old app versions do not understand the text field
