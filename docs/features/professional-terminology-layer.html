Professional Terminology Layer · 专业术语层

Status: preview · version 1.2.1.3 · updated 2026-11-08 dictionaryterminologyprofessionalcloudmachine-learning

What it is. A curated, domain-tagged terminology table prioritised ahead of general dictionary entries, with source/confidence metadata and translation protection.

Problem it solves

General bilingual dictionaries merge everyday senses with professional terms; cloud/CS/ML terms (control plane, etcd, transformer) can be literal, missing or translated inconsistently.

How it works

Schema 7 adds a terms table (word, key, zh, domain, pos, definition, source, confidence). 1,157 entries are loaded from the authored Annota seed and existing curated phrases, covering cloud-native, computer science, ML, science, academic, legal, medical and finance domains. Exact term lookup runs before ordinary entries and renders a technical-term card; the same matches protect sentence translation by replacing residual source terms.

Difference from existing approaches

Terms are an explicit layer with domain and provenance, not a side effect of merging general dictionaries; professional lookup can be reviewed and expanded without touching general vocabulary.

Limitations

  • Seed is author-reviewed but not yet a full 300-term gold evaluation
  • Definitions are concise; no examples by design
  • Reverse Chinese→English term lookup is not part of this layer yet
