# PDF 清晰度与阅读工具验收

2026-10-21，0.1.6-dev / versionCode 7，本地开发候选。公开下载仍是 0.1.5-dev；没有替换既有 Release 附件。

## 核心交互

- 点另一工具立即切换；再次点当前画笔/橡皮才展开参数。记住最近的笔型，切回画笔不会把铅笔、钢笔或荧光笔重置为普通笔。
- 画笔为阅读区域顶部居中的单行图标工具条；横屏、竖屏与缩略图侧栏打开时均跟随实际阅读区中心。笔型、四档粗细、当前主题的五种墨色与白色直接点选；使用既有四套主题的颜色。橡皮、形状和更多为小菜单。
- 菜单不遮暗整页。菜单外的触摸可直接送到工具栏或阅读画布，避免开着菜单时第一次点击被吞掉；原生触摸注入覆盖词典 → 画笔菜单、画笔菜单 → 橡皮及连续往返。
- 选字后在选区旁显示「复制 / 查词」；词典为右上方面板，打开时不自动弹出键盘。搜索栏带查词按钮，键盘与手写入口使用图标；词头和音标置于浅色释义卡片，词性与领域使用统一列宽、首行基线对齐的小标签，相关词条使用带方向图标的圆角行，减少散乱留白。只让释义区域滚动，移除双层滚动容器与固定结果高度，长词条的展开高度上限从 280 增至 380 设计单位；键盘收起后自动扩展。大键盘挤压空间时收起输入方式行和词库说明，保留搜索、关闭与可读释义；隐藏键盘后恢复。选词带入当前句子，离线匹配短语、搭配和词性；默认 1–2 条简释，其他义项主动展开，展开后也保持简短。无证据或歧义冲突时保留备选，手动编辑清除旧语境。覆盖边界与截图见[上下文简释验收](DICTIONARY-CONTEXT-ACCEPTANCE.md)。不新增整句翻译服务。
- 缩略图为左侧栏；长按页面在缩略图右侧显示操作小菜单。阅读器实例在这些操作中保留。

## PDF 与刷新

旧路径使用 PdfRenderer 生成固定分辨率位图，放大时继续拉伸，且缓存键随可见页数变化；没有 JPEG 转码，但显示效果会模糊或短暂退回空白。

现在保留稳定的整页预览，当前可见区域从原始 PDF 按显示比例重新栅格化为 ARGB 分块；相邻分块有一像素重叠。纸张纹理直接绘制，全部内容限定在页面边界内。批注、文字坐标、旋转和导出继续使用原始文档坐标。

分块只请求可见区域，下一行预取整页预览。页面预算从普通应用堆推导，预览与细节分开限额，后台清空、前台重建。按包含边缘分块和双页的**精确总字节数**规划可见细节，并保留余量；内存紧张时降低细节比例，避免可见分块互相挤出缓存。缩放期间显示已有预览，补绘完成后完整可见集合同时驻留。

远距离跳页不再把整个画布透明度降为零。主题切换保留当前 Settings/LibraryScreen 实例，在同一绘制周期更新内容和颜色，保留滚动位置，不再整屏淡入。没有宣称页面从不重绘；重绘本身是正常显示过程。

## 尺子与笔输入

尺子长度随当前可见页面变化，约为可见宽度的 86%，带可读刻度和拖动/双指旋转提示。靠尺边起笔后整笔锁定同一边，避免点位偏离时突然脱离或跳到另一边。

触控笔按实际 pointer ID 取点，保留历史采样与压力，不假设它始终是第零个触点。掌触先落下、触点索引改变、掌触取消和抬笔后残留触点分别处理。笔尾/标准主侧键可临时擦除，松开后保留原选工具；标准系统笔按键忽略重复按下。另加入触控笔即时事件分发、相邻点索引绘制以减少临时分配，并补上抬笔时未经过 MOVE 的真实终点。模拟事件验证这些分支，不证明 Xiaomi 专有手势或真机延迟已适配。三星经验、资料和采用边界见[触控笔优化记录](STYLUS-OPTIMIZATION-NOTES.md)。

## 验证与纠偏

- `reader-fidelity-instrumentation-api36.txt`：54 项原生回归，无跳过；包含原有 38 项、9 项阅读/输入回归与 7 项上下文查词回归。
- 400% 分块与原 PDF 的直接原生渲染逐像素比较，覆盖 0/90/180/270°；缩放补绘时已有页面保留。
- 3408×2272 大视口连续多帧检查**全部可见分块同时驻留**，覆盖真实截图发现的底部模糊缺口；仅统计「这一帧曾画到的分块数」不足以证明完整驻留。
- `reader-fidelity-visual.json`、实际横竖屏 PNG 和原始 `reader-fidelity-motion.mp4`：真实选字点击、长按缩略图、键盘、小菜单、两份 PDF 放大、翻页和主题切换。额外验证大键盘的 420 dpi 系统缩放，检查释义实际可见、长释义滚动、联想词条点击、中英查词、空输入与未收录结果。录像未补帧或重计时，不是帧率/小米设备延迟基准。
- `reader-fidelity-focused-large-keyboard-api36.txt` / `reader-fidelity-large-keyboard.json`：420 dpi 系统缩放的 1 项完整真实视觉流程（上下文与数据回归包含在前述 54 项中）；包含释义列宽/基线一致及扩大后的内容高度。
- `reader-fidelity-apk-local-check.json`：本地完整传输、ZIP/随包 PDF 与词库、版本及开发签名检查。APK 身份与源码哈希见 `reader-fidelity-build.json`。
- lint：0 errors / 75 warnings，仍有建议待处理。

首次完整回归发现直接纸张绘制越出页面，已加页面裁剪；早期失败原文保留在 `reader-fidelity-regression-before.txt`。测试还修正了语言/样例状态隔离、新笔记默认已选中画笔的点击预期，以及视觉脚本在主线程重复调用主线程执行器的问题。

视觉走查纠正了画笔按按钮对齐的偏移，并发现大键盘下即使面板不越界，释义仍可能被控件挤出可视区；现检查有效释义高度及实际可见性。专用模拟器开启软键盘显示，避免硬件键盘抑制使“点击键盘”成为空验证。

视觉走查进一步发现粗略按视口估算内存仍可能造成细节缓存循环淘汰，修正为精确分块预算；真实修正前截图为 `reader-fidelity-zoom-before.png`。模拟器原物理屏幕过小，把 3408×2272 的覆盖尺寸截成 1920×1920；已重启为平板物理屏幕并重拍，最终尺寸清单见 `reader-fidelity-screenshots.json`。
