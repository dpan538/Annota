| 功能 | 问题 | 可量化结果 | 详细设计 |
| --- | --- | --- | --- |
| Contact-Intent Edge Guard | 前臂蹭到屏幕边缘被系统当作返回手势，误退出阅读器 | 合成“前臂+返回”：1.2.0 退出到书库，候选保持阅读器 | [页面](https://dpan538.github.io/Annota/features/contact-intent-edge-guard.html) |
| Ink Transaction Ledger | 抬笔同步整本序列化阻塞 UI，快写断触 | UI submit p50 0.024 ms；抬笔 11.41→7.14 ms；系统 CANCEL 保留已写笔迹 | [页面](https://dpan538.github.io/Annota/features/ink-transaction-ledger.html) |
| Stroke Continuity Reconstruction | 输入丢包导致连笔中断 | 圆弧删 5 点最大偏差 0.001 pt；连笔 0.315 pt | [页面](https://dpan538.github.io/Annota/features/stroke-continuity.html) |
| Ink-Flow Dynamics v6 | 连笔接缝细、阻尼感不足 | 接缝宽度连续性 100.1%；3 pt 小环面积 98.6%；v4/v5 位级不变 | [页面](https://dpan538.github.io/Annota/features/ink-dynamics-v6.html) |

| Page-Picture Ink Cache | 长页每帧逐笔重绘 | 稳态书写帧 2.0–2.9×；像素差 0 | [页面](https://dpan538.github.io/Annota/features/page-picture-cache.html) |
| Offline Context Dictionary | 离线缩写/数字缩合/语境选义 | 40 轮稳态中位数 10.17→4.92 ms；缩写 7/7、领域 7/7 | [页面](https://dpan538.github.io/Annota/features/offline-context-dictionary.html) |
