# 1.0.6-preview · Beta

本轮为 **1.0.6-preview Beta**（versionCode **18**），不是正式稳定版。沿用既有签名，可覆盖安装；最近正式版仍为 1.0.2。默认更新检查提供本 Beta，下载与安装仍需用户确认。

## 连续布局与文件切换

- 打开目录时侧栏从左侧展开，右侧 ReaderView 持续缩小宽度；关闭时反向恢复。不替换阅读视图、不做整屏淡出，保留阅读锚点。
- PDF 打开与返回书库采用方向相反的 180 ms 平移。进入前先准备可见首行底图，最长等待 800 ms；慢文件超过等待上限会继续显示渲染状态，不无限等待。
- 位移期间复用已有底图与高清分块，布局稳定后再计算和请求新分块，减少动画中的渲染竞争。
- 菜单使用短距离平移，按压使用轻微缩放。快速反向切换会取消旧过渡并清理快照，系统关闭动画时直接切换。

## 铅笔黑色

v4 调整纸纹覆盖与压力曲线，让正常阅读比例的黑色更清楚，同时保留轻压、重压、透纸颗粒及重叠加深。屏幕与导出采用同一绘制逻辑。旧笔迹继续按保存的绘制版本显示，请使用新笔迹比较。

## 全量离线词汇与组合词组

此前按词频 / 考试标签筛选的英汉数据会遗漏专业词汇。本轮改为固定版本 ECDICT 中全部非空中文释义，共 **770,238** 条基础记录，另有 **942** 条 Annota 原创词组；英汉合计 **771,180** 条。汉英 **126,272** 条保持随包提供。

未整体收录的词组采用最长片段与来源词形匹配，标为“分段释义”；未知片段保留并标为未收录，不把逐词解释伪装成整句翻译。回归除三个反馈例子外，包含医学、化学、法律、统计与能源词汇及组合。局部语境规则保留，但不声称能够对所有词汇自动消歧。

全部资源在 APK 内，无 Google 翻译、联网词库或语言包下载。英汉 SQLite 在 APK 中压缩存放，首次查词前在设备内展开并验证 SHA-256。代价是安装包约 164 MiB，展开后的英汉与汉英库约 243 MiB。公开来源、固定提交及许可见[词库说明](../design/dictionary/README.md)。

## 最终包验证

- 签名 Release、Debug、AndroidTest 构建与 Lint 通过；最终签名包在断网模拟器完成 **119 项仪器回归**（185.041 s），12 项词库构建回归与 21 个源码单元 / 资源检查通过。
- 动画检查来自实际书库卡片、返回按钮及页面侧栏：打开与返回均记录到中间位移，ReaderView 宽度随侧栏单调变化，透明度保持 1；快速切换与系统关闭动画回归通过。采样不代表目标平板帧率。
- 铅笔初次加深后发现轻重压差距与叠画余量不足，调整覆盖强度和压力曲线后，原有压力 / 透纸 / 叠画断言及新增正常比例对比度断言全部通过。旧版 v3 外观保持。
- UI 测试改为等待位移结束后再点击，并等待菜单屏幕边界稳定后验证完整尺寸；保留无裁切断言。三个反馈词组验证实际面板结果，另有跨学科覆盖与未知片段测试。
- 原有签名、停笔直线、框选旋转、橡皮、阅读、选词、417 页课件缩略图、高清分块和缓存释放回归通过。
- APK 不含 ML Kit 类、Google Translate 跳转或翻译下载归属资源；打包词库解压后的 SHA-256 与清单一致。
