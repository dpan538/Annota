# 黑白 Logo 候选

三组均为白底、黑色标记，尚未指定最终方案：

1. `annota-wordmark-misans.svg`：MiSans 700 的 Annota 纯字标。
2. `annota-notebook-misans.svg`：简洁笔记本轮廓与 MiSans 700 的 N。
3. `annota-notebook-hand.svg`：同一轮廓与使用指南的小赖字体 N，增加笔触厚度。

SVG 使用实际字体字形转为矢量轮廓，字体外观不依赖访问者设备。MiSans 用于制作 Logo 的作品许可与字体软件本身许可不同；本目录不提供 MiSans 字体软件。小赖字体遵循 SIL OFL 1.1。详见根目录 `THIRD_PARTY_NOTICES.md`。
