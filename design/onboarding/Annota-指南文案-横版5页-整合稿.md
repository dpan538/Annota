# Annota 使用指南 · 横版五页整合稿

本稿基于用户提供的改稿，合并信息顺序与按钮层级决定。横版界面已按此结构实现；当前页面的逐字文案同步导出至 `guide-copy.txt`，以该文件核对最终排版文字。

## 版式方案

- 横版 3:2，共五页。标题与手写提示使用小赖字体，正文沿用 MiSans；全部颜色取自项目现有四套主题。
- 第 1 页：两个初始文件的真实封面缩略为视觉主体；另一侧放简短三步，文件整理接在「收起来」之后。
- 第 2 页：阅读界面示意占左侧，三个分区直接标在图旁；右侧放阅读与查词，底部一行练习。
- 第 3 页：四种笔迹横向排列，下方以试写区为主，辅助工具说明放在旁边。
- 第 4 页：左侧四套外观预览，右侧手写笔与手势。每套外观保留完整色板，页面只讲设置。
- 第 5 页：左侧用设备内文件示意解释本地存储，右侧放反馈、更新与 GitHub 入口。
- 每页最多一个实心主按钮。第 1 页「打开示例论文」、第 4 页「打开设置」、第 5 页「提交意见反馈」为主按钮；其他跳转使用文字链接。
- 更新保持用户主动检查与下载，不增加后台自动检查。

## 第 1 页｜开始使用

### 标题

从一份 PDF 开始

### 正文

读 PDF，也写笔记。翻页、选字、查词和批注都在阅读页完成，写下的和标出的内容留在原来的位置。

### 两个初始文件

**Attention Is All You Need**

示例论文。翻页、选字、查词、批注，都拿它试。

**Annota 使用指南**

你正在看的这份。想试笔迹就直接在上面写，写乱了也不要紧。

### 接下来的三步

**打开**

主页里点一个文件开始读；自己的 PDF 走「导入文件」。

**读，顺手写**

手形工具翻页、选字，切到笔就在页面上写。

**收起来**

读完回主页，把文件放到下次找得到的地方。

接在「收起来」后的整理说明：

- **文件夹**：按课程、项目或主题分组。
- **收藏**：阅读页「更多」里收藏，下次从主页左侧「收藏」打开。
- **搜索与筛选**：输入文件名查找，再用筛选缩小范围。

### 入口

- 实心主按钮：打开示例论文
- 文字链接：继续阅读指南 → 第 2 页

## 第 2 页｜阅读与查词

### 标题

顶部有三个区域

### 正文

左边找页面，中间做批注，右边管阅读和其他。用到哪段，就找哪段。

### 界面标注

以下文字贴在图旁，不另做说明卡片：

- **左｜页面**：缩略图，单页 / 双页。
- **中｜批注**：笔、橡皮、直尺、图片、图形、手形。
- **右｜阅读**：新增页面、阅读模式、字典、更多。阅读模式收起书写工具，文档信息放在「更多」里。

### 阅读

**单页 / 双页**

一次看一页，或者并排看两页对照。

**缩略图**

点一下跳页。长按复制、旋转、清除批注或删页；列表底部点「新增页面」。

### 查词

**复制**

手形工具选中文字，浮出的菜单里点「复制」。

**翻译**

选中后点「翻译」，看离线词典释义。也能直接打开右上角字典，用键盘或系统手写输入。支持英汉、汉英查词，不翻整句。

### 练习

在示例论文里选中 attention，复制一次，再查一次。

## 第 3 页｜书写与批注

### 标题

选一支笔，写一句

### 正文

点顶部中间的笔，展开菜单选笔种、粗细和颜色。要翻页的时候切回手形工具。

### 四种笔

**笔**

日常记录就用它，圈划、写字不用来回换。

**铅笔**

颜色淡一些，随手勾个草稿，或记下还没想定的事。

**钢笔**

下笔有轻重，线条也有粗细。

**荧光笔**

半透明地划过，字还看得清。

### 辅助工具

**橡皮**

整笔擦或局部擦。打开「仅荧光笔」后只擦高亮，其他笔迹留着。

**直尺**

拖到位置、转到角度，沿边画线。

**图形**

矩形、圆形、三角形、直线、箭头，用来圈范围或连线。

**图片**

打开系统照片选择器，选好的图插到当前页。

### 试写区

在这儿写一句，画条线，或者圈出一处重点。

### 试写区下方的小字

默认双指点击撤销，三指点击重做；这两个手势在设置里改。

## 第 4 页｜设置

### 标题

调成顺手的样子

### 外观

主页左侧「设置 → 外观」。四套配色，按键大小也能调。

**松间**

深绿配浅蓝，中间用中性色过渡。

**晴昼**

石墨灰配明黄，浅色打底。

**蓝调**

蓝和鼠尾草绿，加一点暖色。

**原野**

黑配牛皮纸棕，浅蓝和橙作点缀。

### 手写笔

「手写笔设置」里改笔身动作和震动反馈。具体能调哪些，取决于笔的型号和系统支持。

### 手势

双指、三指点击各做什么，自己选：撤销、重做、切换工具栏，或者关掉。

### 入口

实心主按钮：打开设置

## 第 5 页｜本地、更新与反馈

### 标题

文件留在本地

### 正文

Annota 不用注册账号，也没有云端空间。PDF、笔记和批注都在这台设备上；阅读、书写、查词断网也能用。

应用只在你主动检查或下载更新，以及提交反馈时联网。

### 意见反馈

从主页打开「意见反馈」，写下当时的操作、出现的情况，或你希望怎样改进。联系方式选填；提交时不会自动附带你的文件和笔记。

### 检查更新

在「设置 → 关于 → 检查更新」查看新版本。更新通过项目的 GitHub Releases 发布。

### GitHub 项目主页

在仓库里看开发进展和版本说明，也欢迎来提问。项目入口通过浏览器打开。

### 入口

- 实心主按钮：提交意见反馈
- 文字链接：检查更新
- 文字链接：GitHub 项目主页

### 项目地址

［待填写正式 GitHub 仓库地址；接入前显示「项目地址即将公布」］

## 本轮内容校正

这一节供审阅，不进入指南页面：

1. 文件整理移到第 1 页，第 4 页只讲设置。
2. 第 1 页保留简短三步，只做入门概览；具体阅读与批注操作留给第 2、3 页。
3. 第 2 页保留界面标注、阅读、查词、练习四块。阅读模式并入右侧标注，词典范围并入查词结尾。
4. 第 5 页反馈为主入口，更新与 GitHub 为文字链接。保留主动检查更新的网络边界。
5. 不把「速度决定笔迹粗细」写进钢笔说明；「笔」也不承诺全程等宽。避免文案超出实际笔迹实现。
6. 首段同时提到 PDF 与笔记，避免把 Annota 描述成只处理 PDF 的工具。
7. 反馈文案直接说明需要哪些信息，去掉对用户表达方式的评价。
