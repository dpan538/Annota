# 随包术语补充

2026-11-02 核对。此处为公开缩写事实、Annota 原创中文简释与规则，不复制 NIST 的整段定义，不表示 NIST 对本应用背书。数据直接放在 APK 的 `dictionary/technical-acronyms.json` 中；来源 URL 仅用于开发核对，运行时不访问。

| 缩写 | 简释 / 歧义 | 核对来源 |
| --- | --- | --- |
| IT | 信息技术 | [NIST IT](https://csrc.nist.gov/glossary/term/it) |
| ICT | 信息与通信技术 | [NIST ICT](https://csrc.nist.gov/glossary/term/ict) |
| CPU | 中央处理器 | [NIST CPU](https://csrc.nist.gov/glossary/term/cpu) |
| RAM | 随机存取存储器 / 随机存取机 | [NIST RAM](https://csrc.nist.gov/glossary/term/ram) |
| VM | 虚拟机 | [NIST VM](https://csrc.nist.gov/glossary/term/vm) |
| DNS | 域名系统 | [NIST DNS](https://csrc.nist.gov/glossary/term/dns) |
| SLA | 服务级别协议 | [NIST SLA](https://csrc.nist.gov/glossary/term/sla) |
| AI | 人工智能 | [NIST AI](https://csrc.nist.gov/glossary/term/ai) |
| IP | 网际协议 / 知识产权 / 外壳防护等级 | [NIST IP](https://csrc.nist.gov/glossary/term/ip) |

选择这些常见计算机缩写是补充通用英汉库的大小写歧义，不宣称覆盖其所有领域含义。全大写及缩写复数保留大小写证据；普通小写不直接套用缩写；相互冲突的上下文不强行消歧。

`measured` 的云资源语境依据 [NIST measured service](https://csrc.nist.gov/glossary/term/measured_service)：该术语涉及资源使用的计量与监测。中文简释为“可计量的”，同时保留实验测量与日常谨慎表达。`scalable` 的系统资源与攀登语境按已有 ECDICT 含义作简释排序。规则存放在 `context-senses.json`，不等同于通用语义理解。

9 个缩写、12 个义项及规则的原创编排遵循项目 MIT 许可；原词库许可保持不变。
