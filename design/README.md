# Annota 主页与设置 UI

公开仓库说明：这是设计与交互原型的源码记录。第三方论文及其页图不随仓库分发，构建方式和 Android 实现状态以根目录 README 为准；以下测试记录来自本地设计环境。

## 范围

Annota 源自 Annotation（批注）。设计 Xiaomi Pad 9 Pro Max 的主页与设置页，保留横屏和竖屏两种布局。用户确认保留六组中的 01、02、03、06，分别命名为松间、晴昼、蓝调、原野。每组仍含 8 个基础色和 2 个预留色。

产品确定为小米平板专用的本地应用。首次打开直接进入书库，不设账号、登录、云空间或跨端同步。PDF、手写笔迹、批注、缩略图、文件夹索引和偏好设置均保存在本机，占用本地存储；读取和手写的核心流程离线可用。公开测试采用相同的本地模式。手写笔与手势仅围绕目标小米设备设计，笔身双击与震动能力仍须通过真机验证。当前交付是 UI 原型，文件存储和阅读功能留待原生实现。

设备画幅以 3408 × 2272（横屏，3:2）和 2272 × 3408（竖屏，2:3）为基准。预览采用等比例设计坐标 1024 × 682⅔ 和 682⅔ × 1024，不将屏幕物理像素直接当作 Android dp。系统栏安全区域、Android 的实际 density 和文字缩放留待原生实现时在目标设备上确认。

屏幕信息参考：[Xiaomi Community 发布介绍](https://new.c.mi.com/ua/post/106256)。

## 固定入口：11 个

| 区域 | 功能 | 数量 |
| --- | --- | --- |
| 左侧导航 | 搜索、主页、收藏；底部设置、意见反馈 | 5 |
| 右侧顶部（从左到右） | 筛选、废纸篓、中英文切换 | 3 |
| 右侧创建区 | 新建笔记、导入文件、新建文件夹 | 3 |

文件夹和笔记卡片是内容入口，不额外计入这 11 个固定功能。笔记卡片显示缩略图、名称和 `2026/10/20 16:01` 格式的完整打开时间；使用 24 小时制，不显示“上次打开”前缀。按最近打开时间默认排序。中英文切换作用于界面标签、设置与筛选弹窗及提示；时间采用相同的数字格式，用户文件与文件夹的原名保持不变。时间缺失的旧预览草稿显示 `--:--`，不伪造打开时间。

## 按键规格

- 最小 60dp，默认 68dp，大号 76dp。
- 设置中的按键尺寸作用于完整点击区域，图标与文字同步适度增大。
- 收藏移到左侧主页下方，显示星形图标与“收藏”文字，选中样式与主页一致。
- 右上角只保留漏斗筛选、废纸篓、语言切换。按钮间无额外间隔，默认点击区域收紧为 60×60 个设计单位；选择大号按键时增至 68×68。最右侧语言图标的可见图形框与创建区、文件夹、笔记网格的右边缘对齐，点击区域向外保留，仍在屏幕范围内。其他按键使用约 24–28dp 图标搭配文字；创建入口至少 88 个设计单位高。
- 横屏侧栏显示图标和横排文字；竖屏收窄侧栏，图标与文字上下排列。两个方向保留全部 11 个固定功能。
- 按键尺寸为原生实现目标；预览中的设计单位用于展示比例，最终 dp 尺寸由 Android 布局实现。

## 设置

设置是完整页面，左侧保留主导航，右侧用四个分类切换内容。选择即时应用并保留在预览状态中。

| 分类 | 内容 | 默认 |
| --- | --- | --- |
| 外观 | 四套主题缩略预览；按键大小 60 / 68 / 76 | 松间、68 |
| 手写笔 | 震动反馈开关；轻点两下切换 | 开启；画笔 / 橡皮擦 |
| 手势 | 双指点击；三指点击 | 撤销；重做 |
| 关于 | Annota 名称来源、用途、MiSans 字体说明、检查更新入口 | 更新服务待接入 |

轻点两下还可选择上一个工具、无操作。双指和三指点击均可选择撤销、重做、显示 / 隐藏工具栏、无操作。当前交互用于配置演示；实际笔身事件、震动和多指手势须在原生阅读页接入设备能力。“检查更新”只预留接口，未连接版本服务，不模拟“已是最新版”。

## 意见反馈

从左侧意见反馈入口打开居中弹窗，背景加半透明遮罩。左上角为取消，中间为标题，底部为整行“提交反馈”按钮。内容只有“问题和建议”多行输入和“联系方式”单行输入；联系方式选填。反馈正文最多 1000 字，联系方式最多 120 字。

取消、点击弹窗外和 Escape 都关闭弹窗，放弃本次未提交修改；点击弹窗内部保持打开。打开时焦点停在取消按钮，背景导航不可操作；关闭后焦点返回意见反馈入口。提交前校验正文非空，预览仅保存草稿并明确提示尚未发送，不调用反馈服务。

弹窗继承当前主题、MiSans 和按键尺寸，最新截图位于 `screenshots/feedback-v2/`，包含四个主题的横竖屏版本，上一版保留在 `screenshots/feedback-v1/`。`export-feedback.cjs` 检查两个输入项、底部整行提交按钮、60 / 68 / 76 三档、中英文布局、两种取消路径、键盘关闭、焦点恢复和草稿流程。

## 形状与布局

- 收回上一版过大的顶部留白：侧栏顶部由 56 改为 48，主内容顶部在默认按键下横屏为 22、竖屏为 16 个设计单位。根据按键档位补偿标题的位置，使“主页”和 Annota 的底边保持对齐；另补偿 MiSans 中英文可见字形的差异。原生版本仍须读取实际系统栏 Insets。
- 设置、意见反馈整体下移，两个点击区域之间的间隔由 10 调整为 0；其下的“本地书库”与按钮组间距从 26 调整为 8。横屏侧栏底部留白为 16。
- 保留规整网格与圆角控制；增加操作区、文件夹和笔记之间的间距，用颜色和边框明确主次。
- 新建与导入是两个强调色按钮；新建文件夹为中性描边按钮。移除创建卡片上的圆环和点阵装饰。
- PDF 缩略图以白纸和双栏排版为主；手写本有小面积彩色封面；公式页有细色条；想法页保留点阵纸。以内容和形态区分类型。
- 主页不增加问候横幅、统计面板或额外工具栏。
- 右上角移除黑色底框，三个图标独立显示。最右图标与内容右边缘对齐；设置页只保留语言图标。
- 横屏：完整左侧栏；右侧依次为标题与管理入口、创建入口、文件夹、四列笔记。
- 竖屏：窄左侧栏；三个图标在标题右侧；文件夹和笔记两列。
- 屏幕画幅固定，书库内容超过画幅时在内容区滚动；预览缩放只用于将两张设备画板放入当前窗口。

## 字体与语言

- 界面统一使用小米 MiSans VF，正文 Regular 400、主要按键和标题 Medium 500。
- 项目保留小米官方服务提供的原始 WOFF2 分片、下载来源与许可文件。预览嵌入所用字符及 400–500 字重范围的子集；原始字体不改动，无需依赖本机安装字体。
- 字体资源位于 `assets/misans/`；设计稿中的设置页注明使用 MiSans。
- 来源：[MiSans 官方页面](https://hyperos.mi.com/font/zh/)，[官方字体说明](https://hyperos.mi.com/font/en/faq/)。
- 右上角语言入口只显示语言图标，一次点击切换中文或英文；可访问名称和提示跟随语言更新。
- 文件名、文件夹名与缩略图内的笔记内容保持原文。手写示例的笔迹风格和公式字形属于内容预览，界面文字使用 MiSans。

## 设计稿交互

首次初始化的书库只包含 **Attention Is All You Need** 和 **Annota 使用指南**。没有预置占位笔记或空文件夹。指南是五页横版可批注内容，分别介绍开始使用与文件整理、阅读与查词、书写与批注、设置，以及本地存储与更新反馈。原生初始化资源与规则见 [首次使用内容](onboarding/README.md)。

主页支持本地演示搜索、收藏与废纸篓切换、筛选、文件夹浏览、按键尺寸调整、新建笔记和文件夹。快速笔记入口先选择空白 / 点阵 / 格子 / 横线及白 / 灰 / 黑底色，然后直接进入可书写页面；纸张模板与底色也能在阅读页的模板菜单调整。导入只接收用户选择的文件名，使用文件占位缩略图，不上传文件，也不模拟已经解析 PDF。意见反馈只保存当前设计稿中的草稿。

任意文件长按约 500ms、右键或键盘菜单键打开文件菜单：收藏、重命名、复制、移动、导出为 PDF、移到废纸篓。菜单靠近触发位置并约束在应用内，点击外部或 Escape 关闭；拖动滚动取消长按。复制保留已打开文档的页面和批注，移到废纸篓后可恢复。行为源为 `library-controls.fragment.html`，原生导出事件见 `NATIVE-INTEGRATION.md`。浏览器对示例 PDF、指南和新笔记提供系统打印 / 保存 PDF 预览，不声称已写出文件。

四种已确认配色通过设置中的外观页切换。示例 PDF 可翻阅真实的 11 页内容；指南可独立打开五页内容，两份文件的页码、批注和图片会话互不混用。打开时间随实际点击更新。阅读器更多菜单支持收藏这份文件，主页左侧收藏同步更新。当前不实现通用 PDF 解析引擎、原生笔迹、整句翻译服务或 Android APK。

`export-screenshots.cjs` 在本机 Chromium 中离线渲染，检查主页图标对齐、日期格式、外观选择、偏好保存与恢复、60 / 68 / 76 三档设置排版和中英文适配。`embed-fonts.py` 补齐原型所用 MiSans 字符并重新生成嵌入子集。

## 阅读界面

功能与范围见 `READER-PLAN.md`。当前源码为 `reader-v2.fragment.html`（持续更新的阅读页源码），通过 `build-reader.py` 嵌入主原型；修改后需重新运行构建，有新文字时运行 `embed-fonts.py` 补齐字体。`reader-ui.fragment.html` 是历史第一版。

- 横竖屏均为单行紧凑顶栏，分为左侧文档导航、屏幕居中的书写工具、右侧阅读选项。三组通过留白区分，不显示侧边或底部常驻控制栏。
- 顶栏共 13 个按钮。图标为 20 个设计单位、线宽 2，按钮槽为 34、选中底为 28；点击笔入口才显示笔类、颜色与粗细。
- 顶部先保留至少 22 个设计单位的系统状态栏安全区域，按钮从纵坐标 24 开始。沿用四套既定主题，蓝调阅读顶栏相对原色 `#4460CE` 仅轻微下调为 `#435DC2`；主页颜色不变。论文周围统一为中性浅灰，纸张保持白色。阅读模式用带正文线条的打开书本，字典用带 A 的书本。
- 左上角页面缩略图改用列表图标，单双页切换用并排页面图标，两者间距 6 个设计单位。侧栏参照 Apple 预览，显示单列纸页缩略图和页码，宽 160 个设计单位；选中时只强调纸页边框与页码，点击跳页并跟随当前页滚动。
- 支持整页 / 适宽、11 页翻页与缩略图跳页、阅读模式，以及原型笔迹、整笔擦除、撤销 / 重做、图形和新增纸页。直尺可移动、旋转，与笔同时启用并沿尺边画直线。默认手形工具。
- “双栏”按用户最新定义表示两张完整 PDF 页面并排：1–2 页 → 3–4 页。左右页独立批注，末尾奇数页单独显示，不裁切正文或重排论文。
- 图片按钮直接打开本地选择器，并保留原生系统 Photo Picker 的事件接口；没有自制上传界面。图片仅在当前会话预览。字典浮窗支持键盘输入、系统手写接口和中英论文术语查询；已独立生成完整汉英库及核心英汉库，原生宿主尚未连接。
- 文件位置、大小、页数和完整名称放入右上角的更多信息，不占阅读区域。
- `render-reader-pdf.py` 只读取源 PDF，输出本地预览页图及源文件校验值，不修改源文件。
- `export-reader-v8.cjs` 导出四套主题、两个方向的截图到 `screenshots/reader-v8/`，检查顶部安全留白、图标语义、纯净阅读底色、单行高度、三组间距与居中，以及双页翻阅、左右页笔迹隔离、直尺移动旋转和贴边绘制、擦除、图片选择及更新接口。历史截图保留在 `reader-v1/` 至 `reader-v7/`。
- 阅读状态只存于当前预览的状态容器；不是 Android 本地书库的持久化实现。
- 原生接入边界与事件约定见 `NATIVE-INTEGRATION.md`；检查更新未连接服务，小米手写笔和 Android Photo Picker 须在原生版本验证。

## 阅读交互与离线词典更新

笔、橡皮、图形均有覆盖 PDF 的悬浮胶囊。橡皮支持整笔 / 局部擦除及仅荧光笔；图形支持五类形状及填充。缩略图末尾可新增页面，长按支持复制、旋转、模板、清除批注和删除，删除与清除可撤销。

全系列手写笔采用能力驱动接口，涵盖 Smart Pen 两代、Focus Pen、Focus Pen Pro、REDMI Smart Pen；浏览器压力和掌触逻辑已测试，硬件接口仍待原生真机验证。

`dictionary/` 已生成 57,841 条核心英汉及 125,301 条汉英 SQLite 数据，合计约 28.94 MiB，供后续安装包携带；含原数据、来源、许可及离线构建/查询程序。阅读预览仍使用小型论文术语表，完整库接入约定见 `NATIVE-INTEGRATION.md`。应用仅在主动检查 / 下载更新或应用内提交反馈时联网。

字典词头 20、释义 15、标题 15 个设计单位；去掉额外解释段落，键盘 / 手写入口使用纯图标。字典及书库搜索均精确匹配优先，支持前缀、中英文关键词和轻微拼写错误候选；字典输入不会改变书库搜索条件。

`extract-reader-text.py` 为这份示例 PDF 提取 11 页真实文本坐标，本地压缩后由 `build-reader.py` 嵌入。手形工具 / 阅读模式支持原生文字选择，选区旁出现复制 / 翻译菜单；复制有成功和失败反馈，翻译复用离线词典，整句翻译未启用时明确提示。`verify-reader-selection.cjs` 覆盖横竖屏选词、复制回退、原生复制回执、查词、句子边界、纯图标入口及左右页文字。扫描件 OCR 与通用 PDF 解析不在本轮实现范围内。

## 初始化指南与 GitHub 配置

`guide-content.fragment.html` 是指南的完整可编辑内容，构建时离线压缩嵌入主原型。当前为 900 × 600 横版五页，包含真实论文缩图、三分区阅读示意、可选择的四种笔迹与试写区；标题嵌入 Xiaolai 手写字体子集，正文沿用 MiSans。指南只使用四套既定主题的颜色，黄色为晴昼 `#FFDA4C`；试笔卡采用已有浅蓝、薄荷、淡蓝与浅黄。完整文案导出至 `onboarding/guide-copy.txt`。指南内也可进入示例论文、外观设置、关于更新及意见反馈。`build-onboarding.py` 将真实 PDF、指南内容源、字体 OFL 许可和带 SHA-256 的清单写入 `onboarding/bundle/`，供原生打包使用；不表示已生成 APK。

`project.config.json` 统一保存项目配置。`repository` 尚未提供，保持 `null`；指南如实显示“项目地址即将公布”。检查更新事件指定 `github-releases`，后续读取正式 Release 的 APK 资产；GitHub 项目主页通过外部浏览器打开。反馈提供方为 `in-app`，通过宿主提交正文和选填联系方式；`feedbackEndpoint` 未配置时只保留草稿。没有后台自动检查、登录或云同步。

`ANNOTA_GUIDE_ONLY=1 node design/export-reader-v8.cjs` 检查两份初始文件、五页版式、入口跳转、独立批注、收藏与恢复，截图和结果在 `screenshots/onboarding-v1/`。原型的旧占位文件会迁移，用户创建的文件保留；版本 2 初始化后不重复补回用户已删除的预置文件。

`ANNOTA_LIBRARY_ONLY=1 node design/export-reader-v8.cjs` 检查横竖屏文件长按菜单、全部六种文件操作、四种纸张 × 三种底色、黑纸书写、复制批注、导出桥接及 11 页系统打印预览、状态恢复，结果在 `screenshots/library-v1/`。
