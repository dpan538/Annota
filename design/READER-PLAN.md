# Annota 阅读界面

为小米 Pad 9 Pro Max 设计横屏与竖屏两种布局，使用 MiSans 和已确定的四套配色。阅读页按用户提供的 Goodnotes 截图比例采用单行紧凑顶栏。

## 功能范围

| 功能 | 第一版交互 |
| --- | --- |
| 阅读 | 返回书库、左右滑动翻页、缩略图跳页、整页 / 适宽、阅读模式 |
| 手写批注 | 笔、铅笔、钢笔、荧光笔；悬浮胶囊内切换笔类、三档粗细、五种主题墨色 |
| 词典 / 翻译 | 可输入的浮窗；键盘 / 系统手写入口，原创中英论文术语查询；完整离线词库已独立构建，待原生宿主接入 |
| 双页并排 | 左上角切换单页 / 双页；两张完整 PDF 页面同时显示，按第 1–2 页 → 第 3–4 页翻阅 |
| 新增页面 | 顶栏在当前页后插入；缩略图列表末尾追加空白、横线、点阵或格子页 |
| 辅助工具 | 尺、图片、图形；手形工具停用书写并用于拖动、翻页 |
| 本地保存 | 正式应用保存原 PDF、独立笔迹层、阅读进度与设置；本次仅演示原型状态保存 |

## 顶栏的三个独立功能区

- 左侧：返回、文件名、页面缩略图、单双页切换。缩略图用 `layout-list` 列表图标，双页用 `columns-2` 并排页面图标；两个按钮之间留 6 个设计单位，避免相似轮廓连在一起。竖屏隐藏文件名，完整名称仍可从更多信息查看。
- 居中：笔类、橡皮、尺、图片、图形、手。四种笔合并在笔入口的浮层里，参数不占常驻第二排。
- 右侧：新增页面、阅读模式、字典、更多，顺序固定。阅读模式用带正文线条的打开书本 `book-open-text`，字典用带字母 A 的书本 `book-a`。

横竖屏均为 13 个常驻按钮。中间工具组对齐整个屏幕中心，左右两组贴近各自屏幕边缘；组间留白，组内紧凑排列，不增加底框或分隔栏。

在 1024 宽的横屏设计坐标下，图标框为 20，线宽 2，按钮槽为 34，选中底为 28。顶部为系统状态栏保留至少 22 个设计单位，再留 2 个单位间距，按钮从纵坐标 24 开始；默认顶栏总高 62。原型不绘制虚假的系统时间或电量；原生 Android 实现应依据实际 WindowInsets 保留状态栏区域，并让系统图标与顶栏明暗匹配。

这些是匹配用户截图的视觉比例，不是 Android dp 标注；原生触控范围须依据设备实际 density 确定。阅读顶栏独立于书库的大按钮设置，60 / 68 / 76 档不再放大阅读图标。悬浮胶囊按钮采用 30×32 设计单位，页面菜单行高 42；正式触控区域按设备 density 验收。

## 阅读页的配色分工

四套已确认主题用于应用顶栏及工具选中态；蓝调阅读顶栏相对原色 `#4460CE` 仅轻微下调为 `#435DC2`，主页色板不变：

| 主题 | 顶栏 | 选中态 |
| --- | --- | --- |
| 松间 | 松绿 `#1C614C` | 天蓝 `#BFD4E9` |
| 晴昼 | 石墨灰 `#5D6769` | 黄 `#FFDA4C` |
| 蓝调 | 钴蓝 `#435DC2` | 浅蓝底 `#E5EAFA`、深蓝图标 `#3F55AD` |
| 原野 | 棕 `#A28D70` | 近黑 `#27282A`、白图标 |

四套主题的阅读背景统一为中性浅灰 `#F4F4F4`，PDF 保持原始白色纸面。笔记默认白纸，另提供灰、黑两种底色；黑纸默认使用浅色墨迹。论文周围不使用书库的鼠尾草绿底色。笔迹、高亮和查词仍使用各主题已预留的颜色；默认页面不铺装饰性色块。

## 页面布局

- 横竖屏均为单行顶栏，其下只显示论文；默认不显示侧栏、底部控制栏或笔触参数。
- 侧边栏参考 [Apple 预览的缩略图导航](https://support.apple.com/zh-hans/guide/preview/prvw11470/11.0/mac/27)，改为单列页面缩略图与页码。侧栏宽 160 个设计单位，缩略图为白纸，无大号圆角卡片；选中页使用细蓝框和页码底色。点击跳页，滚动独立于正文，翻页后使当前缩略图保持可见；再次点击顶栏入口收起。适宽时正文区域纵向滚动。
- “双栏”按用户最新定义表示双页并排，不表示论文正文的栏数。两页保留完整版式，不裁切、不重排；双页模式中缩略图同时标记当前的两页，跳转到页所在的一组。
- 双页批注分别归属左右页；撤销 / 重做按整个文档的操作顺序执行，也可恢复页面复制、删除、旋转和清空批注。奇数总页数的末尾只显示最后一页，右侧不生成虚假内容。
- 阅读模式隐藏居中的书写工具并启用手形工具，保留左右功能区位置。
- 本地文件位置、文件大小、页数、完整文件名，以及整页 / 适宽、撤销 / 重做，均放入右侧更多浮层。
- PDF 内容使用原文版式与字体；MiSans 用于应用界面，不替换论文字体。

## 示例与实现边界

首次初始化只生成 `Attention Is All You Need` 与 `Annota 使用指南` 两份文件。指南为 900 × 600 的横版五页可批注笔记，覆盖核心操作和完整用户流程；源码在 `guide-content.fragment.html`。手写标题配 MiSans 正文，颜色全部取自四套主题。各文档的阅读位置、页面顺序、图片会话和批注分开管理；不在更新或启动时重复补回用户删除的初始文件。资源清单与原生初始化约定见 `onboarding/README.md`。

书库任意文件长按可收藏、重命名、复制、移动、导出 PDF 或移到废纸篓。快速笔记先选空白 / 点阵 / 格子 / 横线，以及白 / 灰 / 黑底色，创建后直接进入书写；原型副本也可打开并保留原批注。已知文档可走浏览器系统打印预览，原生导出接管 `annota:export-document` 事件。

示例来自用户提供的 `NIPS-2017-attention-is-all-you-need-Paper.pdf`，11 页。保存原文，不修改用户源文件；本地渲染页图供 UI 展示。全部 11 页可以翻阅。

这是 HTML 交互原型，不是原生 Android PDF 引擎。手写演示支持鼠标 / PointerEvent 触控笔，最多保留 16 条、每条 48 点，避免原型状态膨胀；不应作为真实笔记存储使用。浏览器已处理压力、笔触采样、掌触过滤、取消笔画及双 / 三指点击；小米各代笔的型号和能力事件接口已预留。笔身双击、实际震动和输入体验仍需原生接入及真机验证。状态快照超出预算时降低笔迹采样点数，不用于正式笔记保存。

直尺可独立开关、拖动和旋转；笔可与直尺同时启用，靠近尺边落笔时投影成直线。橡皮胶囊提供整笔 / 局部擦除、三档尺寸、仅擦荧光笔；局部擦除会分割原笔迹。图形胶囊提供矩形、椭圆、三角形、直线、箭头，三档线宽、五种墨色和封闭图形填充。新增纸页保存在预览状态中，不修改源 PDF。

图片按钮直接调用浏览器本地文件选择器，预留原生系统 Photo Picker 事件接口；没有自制上传面板。插入图片只在当前会话预览，不上传、不写入 PDF，也不保存在预览快照中。Android 系统选择器与 Xiaomi 设备能力尚未接入。接口约定见 `NATIVE-INTEGRATION.md`。

设置 → 关于新增“检查更新”入口，预留更新事件；未连接版本服务时如实显示未接入状态。不加入账号或云同步。

更新提供方为 GitHub Releases，真实仓库地址待配置于 `project.config.json`。应用仅在主动检查 / 下载更新或应用内提交反馈时联网；反馈服务未配置时保留草稿，不模拟发送成功。指南最后一页强调纯本地、无需账号，并提供更新、反馈及 GitHub 入口。

词典浮窗宽 346 设计单位，覆盖在阅读区右上方，包含可编辑输入框、键盘 / 手写图标、结果和示例词。词头 20、释义 15、标题 15 个设计单位，取消额外解释段落。精确匹配优先，前缀、中文关键词、漏字母及相邻字母交换给出可点选候选。预览内置约 30 条原创论文术语，英中均可查；离线 SQLite 词库已构建并通过独立查询测试，但尚未接入 Android 宿主。不提供整句翻译或自动联网查词。通用 PDF 导入当前仍只有文件名占位，只有这一份用户提供的示例文档具备真实页图及可选取文字层。

手形工具和阅读模式可选取文字；旁边浮动菜单提供复制、翻译。复制使用浏览器本地能力，并提供原生剪贴板接口与真实失败提示；翻译复用离线词典浮窗。整句没有匹配短语时明确说明不支持整句翻译，不以单词释义代替。文字层随完整纸页缩放和旋转，双页各自使用对应的原文内容；写字模式不触发文本选择。

## 缩略图页面菜单

侧栏底部的虚线纸页用于追加页面；缩略图长按约 480ms 或鼠标右键打开就近菜单，拖动滚动取消长按。支持复制（含批注）、顺时针旋转 90°、更换手写页纸张模板、清除批注和删除。PDF 原文页禁用更换模板；清除与删除二次确认，可撤销；最后一页不可删除。菜单不会越过阅读区底部。预览最多 40 页。

## 本轮验证

`export-reader-v8.cjs` 在本地 Chromium 中检查四套主题与横竖屏布局，导出侧栏、双页并排、双页加侧栏、笔与直尺、关于更新入口等截图。交互覆盖双页成组翻页、末尾单页、右页独立书写、撤销重做、直尺移动旋转与贴边画线、直线中段擦除、原生图片事件及浏览器选择器回退、更新占位事件。测试不代替小米设备实测。

`verify-reader-details.cjs` 检查三个胶囊、局部擦除与恢复、长按页面操作、末尾新增、纸张模板、中英查询、模糊搜索、输入法和离线字典回调、过期结果隔离、五个型号的能力协议、压力/掌触取消隔离及双三指撤销重做。`verify-reader-selection.cjs` 增加横竖屏文字选取、复制、翻译及阅读 / 书写模式隔离。完整流程报告在 `screenshots/reader-v8/checks.json`；词库另有 5 项本地数据库测试。所有浏览器网络请求均被阻止，未以此替代 Android 真机验收。

另以 `ANNOTA_GUIDE_ONLY=1` 验证横版五页指南、试笔卡排版与链接；以 `ANNOTA_LIBRARY_ONLY=1` 验证文件菜单、12 种纸张组合、黑纸书写、复制批注和系统导出预览。
