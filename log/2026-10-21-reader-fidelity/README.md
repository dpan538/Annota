# PDF 清晰度与阅读工具

用户提供六张 Xiaomi 实际截图与六张既有设计参考，优先指出固定小图放大后的模糊、画笔/橡皮切换及遮挡阅读的大弹窗。

本轮在原生 Kotlin 阅读器修正高清分块、稳定预览、小菜单和图标参数条、一击工具切换、居中画笔菜单、响应式词典/缩略图、尺边输入，以及跳页和主题切换的整屏淡入。完整实现、取舍和未验收项见[验收记录](../../docs/READER-FIDELITY-ACCEPTANCE.md)。

关键纠偏是原生截图发现「已画到全部分块」仍可能随后出现模糊缺口：可见分块总量超过 LRU 限额。按实际区域字节数预算并检查完整驻留后再次验收；修正前 PNG 与早期失败记录一并保留。

画笔在横屏、竖屏与缩略图侧栏均按阅读区居中。词典使用单一释义滚动区，真实键盘可见时固定搜索栏；大键盘下收起辅助行，保证释义可见。验证中修正了只检测点击、却未实际显示软键盘的不足。

54 项 API36 ARM64 原生回归与独立视觉流程分开归档。截图为真实 3408×2272 / 2272×3408 显示，录屏保留原始编码，不冒充真机帧率或旧版 316 轮的长时成绩。证据在 [Android verification](../../android/verification/README.md) 的 `reader-fidelity-*` 文件中。

0.1.6-dev (7) 是本地开发候选，未发布到 GitHub；0.1.5 的公开 APK 原件未变。后续修改或发布应继续保留中英文提交标题与完整正文。
