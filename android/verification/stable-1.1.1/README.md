# 1.1.1 待发布验证

本目录是开发验收证据，不代表公开发布或真机验收。未创建 Release、tag、公开 APK 或更新通道。

- `regression.txt`：129 项相关 Android 回归全部通过，包含原有笔迹、PDF、渲染、词典、阅读、更新解析等测试。
- `language-ui.txt`：最终候选上重跑译文显示、快速改词与关闭取消，1 项通过；`offline-translation-panel-111.png` 是合成用例截图。
- `focused.txt`：前期 16 项阅读/菜单定向测试；最终同类检查包含在全量回归中。
- `lexicon-python.txt`：14 项离线词库构建/查找回归。
- `lexicon-coverage.json`：筛选后词头数量与相对旧库差集，不是准确率。
- `offline-translation-111.json`：真实 Android CPU 输出与热解码时间（不含初始化/首次复制）。五个探针并非通用翻译评测；已知错译见调研记录。
- `apk-check.json`：最终包哈希、原安装证书、资产校验、ARM64 库、覆盖安装和冷启动。下载路径为临时 loopback，仅验证字节链路，未验证公开 GitHub 下载。
- `validation.json`：汇总与未完成的真机复核范围。最终包仅更新开源署名后重打，运行时代码与 129 项回归所测版本相同；在最终包上再次检查签名、冷启动与翻译面板。

包约 316 MiB。模型资源全部内置，首次使用还会在应用目录准备模型文件；没有首次联网下载。默认公开稳定版仍是 1.1.0。
